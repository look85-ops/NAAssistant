# Транскрипты сессий

Хранилище саммари значимых сессий — чтобы возобновлять старые темы без потери контекста и tacit knowledge.  
Пишет ассистент по простому запросу Наташи («запиши про X») или сам предлагает после значимой сессии.

## Формат файла

Имя: `YYYY-MM-DD_тема.md`  
Структура:

```markdown
# [Дата] — [Тема]

**Контекст:** с чего начали, что было на входе
**Ключевые решения:** что решили, почему (1-3 пункта)
**Артефакты:** что создали/изменили (файлы, ссылки)
**Tacit knowledge:** что поняли между строк — нюансы, интуиция, неочевидные связи
```

## Правила

- Триггер — простая речь Наташи, не команда.
- Один файл = одна значимая сессия (не каждый чих).
- Архивариус обновляет `knowledge/index.md` при новых темах.
- Архитектор следит за форматом и отнесением к доменам.
- Директор по развитию читает раз в месяц (`/monthly-audit`).
