## 4. Риски и безопасность

### Текущие риски (по убыванию)

| Риск | Уровень | Проект | Что делать |
|---|---|---|---|
| API-ключи в открытом репозитории | 🔴 **Критический** | Амальгамма | Срочно убрать в Secrets |
| Bothub proxy — неофициальный провайдер | 🟡 Средний | Амальгамма, Horoscope | Перевести на OpenRouter (официальный) или прямой API DeepSeek |
| Расход токенов Амальгаммы ×2 от бюджета | 🟡 Средний | Амальгамма | Починить Loop Harness (LLM-судья выдаёт FAIL = не считает токены) |
| Данные РЖД в AI-пайплайне | 🟡 Средний | Курсы | Не передавать закрытые данные через внешние API. Использовать локальную LLM (через Ollama) или обезличивать |
| Зависимость от Claude (ассистент) | 🟢 Низкий | Все | Резерв: ChatGPT, DeepSeek через OpenRouter |

### Принципы AI-безопасности (на будущее)

1. **Локальность:** чувствительные данные — только локальная LLM (Ollama / LM Studio)
2. **Без ключей в гите:** все ключи через env/GitHub Secrets
3. **Прозрачность:** каждый AI-вывод проверяем на здравый смысл (Human-in-the-Loop для постов, резюме, стратегии)
4. **Fallback:** если провайдер не отвечает → переключение на резервный (уже реализовано в Амальгамме)
5. **Метрики:** для AI-функций считаем accuracy (совпало/не совпало с ожиданием)
