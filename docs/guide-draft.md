# ЧАСТЬ I. ПОНИМАНИЕ

## 1. AI-агент простыми словами

### Чат — это прохожий на улице

Вы задаёте вопрос → вам отвечают. Каждый раз с чистого листа. Он забывает контекст и ему всё равно, кто вы и что для вас важно.

### Агент — это сотрудник, которому вы дали должностную инструкцию

Один раз описываете:

- **Кто вы**
- **Что вам нужно**
- **Как отвечать**
- **Что важно**

Дальше он работает сам. Не нужно каждый раз объяснять и напоминать задачу. Он помнит контекст, файлы, решения, которые вы уже принимали.

### Что реально меняется

| Без агента | С агентом |
|-----------|-----------|
| «Напиши сопроводительное для — далее копирование вакансии и своего резюме» | «Напиши сопроводительное на вакансию в файле» |
| Каждый раз объясняете: кто вы, где живёте, что умеете | Один раз описали — он помнит |
| GPT предлагает «динамичный молодой коллектив» | Агент знает: у вас запрет на канцелярит |
| Один результат за раз, память до конца лимита токенов в диалоге | Проект живёт, копит знания, растёт с вами |

## 2. Три уровня AI-помощника

Не бросайтесь сразу к сложному. Начните с того, что подходит под вашу задачу.

### Уровень 1. Обычный чат (Claude.ai, ChatGPT, DeepSeek)

**Когда достаточно:** разовые вопросы, черновики, поиск информации.

**Когда мало:** нужно, чтобы AI помнил вас между сессиями и работал с вашими файлами.

### Уровень 2. GPT / Claude Project (5 минут на настройку)

Это чат + постоянная инструкция + прикреплённые файлы.

**Когда достаточно:** одна повторяющаяся задача (например, «редактируй мои посты по этим правилам»).

**Когда мало:** нужно несколько связанных задач, автоматизация, работа с сайтом или кодом.

### Уровень 3. Полноценный агент через Opencode — 30 минут на настройку

Opencode (или аналоги) — это AI, который живёт в папке на вашем компьютере, видит все файлы, редактирует их, копит знания, умеет запускать несколько специализированных суб-агентов.

**Когда нужен:** ведёте несколько проектов, хотите строить продукты (сайт, аналитику, дайджест), нужна долгая память и структура.

**Этот гайд — про третий уровень.** Но принципы работают на всех.

---

## 3. Что агенты умеют — и чего не умеют

### Умеют

- Помнить контекст неделями и месяцами
- Читать ваши файлы (PDF, Word, Excel, CSV — всё, что положите в папку)
- Редактировать документы (резюме, посты, сценарии, аналитику)
- Собирать простые сайты и веб-инструменты (HTML/CSS/JS)
- Искать в интернете (если разрешить)
- Считать метрики по опросам, писать отчёты
- Работать в связке: один агент придумывает, второй проверяет, третий пишет

### Не умеют

- Читать ваши мысли (нужно объяснять контекст)
- Гарантировать 100% точность (проверяйте факты и цифры)
- Заходить в ваши личные кабинеты без специальной интеграции
- Заменить экспертное суждение (агент — усилитель, не подмена)
- Держать секреты в тайне, если вы сами их выложили (см. Часть VI, приватность)

### Правило проверки

Каждый ответ агента проверяйте на здравый смысл. Особенно цифры, даты, ссылки. Он может уверенно ошибаться.

Полезно вшить в «геном» агента промпты самопроверки — короткий чек-лист, который агент прогоняет по каждому ответу перед выдачей. Например: «Все цифры взяты из источника, а не придуманы? Все ссылки реальные? Нет ли фраз, которые я обычно правлю?». Один раз описываете — агент проверяет себя сам.

# ЧАСТЬ II. ЗАПУСК ЗА 30 МИНУТ

## 4. Что понадобится

**Обязательно:**
- Компьютер с интернетом (Windows или Mac)
- Электронная почта (для регистрации)
- 15–30 минут времени
- API-ключ (см. п. 6)

**Опционально:**
- $5–10 на первый месяц использования (можно и бесплатно)
- Файлы, с которыми будете работать (резюме, заметки, что угодно)

**Не нужно:**
- Знать программирование
- Иметь техническое образование

## 5. Установка opencode

### Самый простой путь: OpenCode Desktop (Beta)

Для гуманитариев — не нужен терминал вообще. Скачайте настольную версию:

- Официальный сайт: **opencode.ai**
- Документация на русском: [opencode.ai/docs/ru](https://opencode.ai/docs/ru)

Порядок: скачали → установили как обычную программу → запустили → указали папку проекта → всё готово.

### Примечание

Если у вас специальная среда (например, корпоративный ноутбук с ограничениями), мы поможем подобрать вариант установки и запуска под ваши условия. Для большинства гуманитариев достаточно Desktop-версии.

## 6. API-ключ: где взять и сколько стоит

### Что это

Ключ — это ваш «пропуск» к AI-модели. Вы платите не за opencode (он бесплатный), а за то, что AI отвечает на ваши сообщения.

### Варианты

**Anthropic (Claude)** — рекомендую для начала
- Сайт: console.anthropic.com
- Стоимость: ~$3 за 1 млн входящих слов, ~$15 за 1 млн исходящих
- В реальности: активное использование — $10–30 в месяц

**OpenRouter** — доступ ко многим моделям сразу
- Сайт: openrouter.ai
- Плюс: можно выбирать бесплатные модели (медленнее, но $0)
- Стоимость зависит от модели

**Бесплатные варианты**
- В самом opencode можно выбрать модели с меткой «free»
- Локальные модели (Ollama) — сложнее в настройке, но бесплатно

### Как настроить ключ в opencode

1. Зарегистрируйтесь на выбранной платформе
2. В личном кабинете найдите раздел «API keys» → создайте ключ
3. Скопируйте ключ (это длинная строка типа `sk-ant-api03-...`)
4. Запустите opencode → в настройках (значок «шестерёнка») → «Провайдеры» → выберите вашего провайдера из списка (если подключаетесь через агрегатор вроде Bothub — выберите «Пользовательский провайдер») → нажмите «Подключить» → заполните поля → нажмите «Отправить»

### Безопасность

- Не показывайте ключ никому
- Не выкладывайте в интернет
- Если случайно опубликовали — сразу удалите и создайте новый

## 7. Первое сообщение: формула

**Вы не пишете файлы. Вы описываете себя и задачу — агент делает всё сам.**

### Шаги

```
1. Создайте пустую папку на компьютере (например, «мой-ассистент»)
2. Откройте OpenCode Desktop → укажите созданную папку проекта
3. Вводите первое сообщение по шаблону ниже
4. Смотрите, как агент разворачивает структуру и задаёт уточняющие вопросы
```

### Формула первого промпта (7 блоков)

```
1. КТО Я
   Имя, возраст, чем занимаюсь, ключевые обстоятельства

2. ЗАЧЕМ АГЕНТ
   Основная задача, для которой заводим ассистента

3. КАК ОБРАЩАТЬСЯ
   На «ты» или «вы», как зовут, стиль общения

4. КАК ОТВЕЧАТЬ
   Длина ответа, формат, что НЕ использовать (жаргон, эмодзи, воду)

5. МОИ ГРАНИЦЫ
   Чего избегать, чувствительные темы, что я НЕ хочу обсуждать

6. КАК Я ПРИНИМАЮ РЕШЕНИЯ
   Даю ли я сам делать что-то, или всегда подтверждаю

7. ЧТО СДЕЛАТЬ ПРЯМО СЕЙЧАС
   Первое задание: развернуть структуру, задать вопросы, что-то создать
```

### Готовый шаблон (копируйте, заменяйте контекст)

> Привет. Я [ИМЯ], мне [ВОЗРАСТ] лет, я работаю [ПРОФЕССИЯ]. Мой контекст: [2–3 главных обстоятельства — переезд, поиск работы, проект и т.д.].
>
> Мне нужен ассистент, который поможет с [ГЛАВНАЯ ЗАДАЧА].
>
> Правила общения:
> — обращайся ко мне на «ты», зови [ИМЯ]
> — отвечай коротко (не больше 4–5 строк, если не прошу подробнее)
> — без эмодзи, без канцелярита, без «синергии» и «трансформации»
> — я гуманитарий: объясняй технические вещи простыми словами и мини-примерами
> — если термин неизбежен — дай определение в одну строку
>
> Мои границы:
> — не утешай, если я тревожусь. Дай факты и следующий шаг
> — если я придумываю новые идеи — не гаси, но проверяй на прочность (что даст через месяц, какой минимальный шаг)
> — если не уверен в задаче — уточни, прежде чем делать
>
> Что делать сейчас:
> Развернь структуру проекта под мою задачу. Создай нужные папки и файлы, чтобы ты мог копить знания, записывать решения, вести бэклог задач. Начни с **AGENTS.md**.
>
> Мне не нужно знать про формат файлов — просто делай, что нужно. По ходу задавай уточняющие вопросы.

### Что произойдёт после этого сообщения

Агент за несколько минут:

- Создаст **AGENTS.md** — вашу «конституцию» (кто вы, что нужно, как работать)
- Создаст **папки**: knowledge/ (память), logs/ (решения), docs/ (документы)
- Создаст **первый суб-агент** под вашу задачу
- Создаст **бэклог задач**, чтобы вести список дел
- Задаст 2–3 уточняющих вопроса

Всё это — из одного сообщения. Вы не пишете ни строки кода.

# ЧАСТЬ III. РАБОТА С АГЕНТОМ

## 8. Как давать задачи: плохой vs хороший запрос

### Плохой запрос

> «Напиши пост в LinkedIn»

Что не так: агент не знает тему, аудиторию, тон, длину, цель.

### Средний запрос

> «Напиши пост в LinkedIn про AI в обучении»

Уже лучше, но всё ещё много неизвестного.

### Хороший запрос

> «Напиши черновик поста в LinkedIn: тема — как я использую AI-агентов в L&D. Аудитория — методологи корпобучения. Формат: короткая история из практики + один инсайт + вопрос читателю. Длина 150 слов. Тон — как в моих прошлых постах в career/posts/.»

Что изменилось: тема, аудитория, формат, длина, тон.

### Формула хорошего запроса

```
[ЧТО СДЕЛАТЬ] + [ДЛЯ КОГО] + [В КАКОМ ФОРМАТЕ] + [С УЧЁТОМ ЧЕГО]
```

### Ещё лучше: покажите пример

Агент лучше всего работает по образцу. Если у вас есть примеры хороших постов/писем/отчётов — просто дайте ссылку на файл в разговоре: «делай в стиле career/posts/post-2026-06-01.md».

---

## 9. Как исправлять и обучать агента

### Когда агент ошибся

Просто скажите, что не так, и покажите, как правильно. Например:

> «Ты написала слишком формально. Убери "представляется целесообразным". У меня в правилах есть запрет на канцелярит — обнови knowledge, чтобы больше не забывать.»

Агент:

1. Перепишет ответ по-новому
2. Запишет правило в свою память (файл knowledge/)
3. В следующий раз не повторит ошибку

### Три типа обратной связи

**Разовая правка:** «Перепиши покороче» — агент правит, но правило не запоминает.

**Правило на будущее:** «Всегда пиши покороче и запиши это в knowledge» — правило сохранится.

**Обновление контекста:** «Мой рынок поменялся, теперь я ищу работу в FMCG, а не в полиграфии. Обнови AGENTS.md.» — агент правит свою конституцию.

### Что запоминать, а что — нет

Запоминать (в knowledge/):
- Повторяющиеся правила стиля
- Ваши предпочтения по формату
- Уроки, что сработало и что нет
- Ключевые данные о вас, которые агент должен знать всегда

Не запоминать (просто разовая правка):
- Мелкие правки под конкретный текст
- Одноразовые запросы

## 10. Уровни доверия

Вы решаете, что агент может делать сам, а что — только с вашего разрешения.

| Уровень | Что делает | Пример |
|---------|-----------|--------|
| Зелёный (сам) | Правит файлы, создаёт структуру, ведёт бэклог | «Обнови knowledge/» — делает сразу |
| Жёлтый (с ОК) | Предлагает вариант, вы утверждаете | Черновик поста → вы правите → публикуете |
| Красный (только вы) | Стратегические решения, деньги, личные данные | Смена карьерного вектора, крупные покупки |

### Как задать уровни

Просто скажите в первом промпте или потом:

> «Правки в моих файлах делай сам, не спрашивай. Посты и резюме — сначала показывай мне. Смену карьерных целей никогда не решай сама — только я.»

Агент запишет это в правила.

### Как это меняется со временем

Чем дольше работаете, тем больше уходит в зелёный: агент учится, ошибок меньше, вы доверяете больше.

# ЧАСТЬ IV. РАЗВИТИЕ

## 11. Как добавить второго агента

Один агент — это хорошо. Несколько специализированных — ещё лучше. Каждый со своей ролью и памятью.

### Когда пора

Когда чувствуете, что «универсальный» ассистент начинает путаться между задачами. Например, вы просите его писать резюме и посты — разные стили, разные аудитории, но он смешивает их.

### Как добавить

Просто скажите:

> «Мне нужен отдельный агент — редактор постов для LinkedIn. Он должен: анализировать мои черновики, править под мою аудиторию (методологи и edtech), убирать канцелярит. Не пишет с нуля — только правит. Создай его.»

Агент:

1. Создаст новый файл со специализацией
2. Пропишет зоны ответственности
3. Свяжет с существующей структурой (папка постов и т.д.)

### Полезные суб-агенты (реальные примеры)

- **Карьерный стратег** — резюме, вакансии, сопроводительные
- **Редактор постов** — правки контента, стиль
- **Аналитик опросов** — метрики, инсайты, рекомендации
- **Педагогический дизайнер** — сценарии обучения по шаблону
- **Продуктовый аналитик** — превращает идеи в задачи бэклога
- **Фронтенд-разработчик** — собирает HTML-страницы по описанию

Каждый — отдельный файл, отдельная память, отдельная роль.

### Веб-страницы и сервисы

5 инструментов для методологов: симулятор учебного дня, генератор активностей, карты фасилитации, аудит запроса, мастер видения продукта. Всё на одном сайте с деплоем в интернет. Создано агентом по ТЗ.

Одна HTML-страница с анимированным пушистым существом, которое реагирует на курсор. Никакого сервера, ноль строк кода — я только описала настроение и поведение.

### Пример 4. Дайджест и регулярный контент через скиллы

**Скилл** — это готовый «модуль» с инструкциями для агента под одну повторяющуюся задачу. Условно — рецепт, по которому агент всегда действует одинаково.

Например, у меня раз в две недели выходит «L&D × AI Дайджест». Один раз я собрала скилл — прописала: где искать источники, какие блоки в выпуске, какой стиль, куда сохранять. Теперь одна команда — и агент проходит весь цикл сам:

1. Ищет свежие новости и статьи по теме
2. Формирует 4 блока: кейс недели, инструмент под задачу, метрика, три ссылки
3. Показывает мне черновик
4. Я правлю, он публикует

Скилл можно собрать под любую регулярную задачу: еженедельный отчёт, разбор новостей, обзор рынка, ретроспектива недели. Просто попросите агента: «Собери мне скилл под задачу X. Опиши, что он должен делать по шагам».

Ссылки:
- Страница дайджеста (GH Pages): https://look85-ops.github.io/methodist-booster/digest/

### Аналитика и работа с файлами (Python)

Если установить на компьютер **Python** (бесплатная программа для запуска скриптов), возможности агента резко расширяются. Он сможет:

- **Считать аналитику** по вашим CSV / Excel: средние, распределения, аномалии
- **Создавать документы**: Word, Excel, PDF — по шаблонам, с вашими данными
- **Строить дашборды**: простые интерактивные графики в браузере
- **Обрабатывать много файлов сразу**: переименовать 200 фото, объединить 50 таблиц

Как это выглядит: вы говорите — «загрузи CSV с опросом, посчитай метрики, сделай PDF-отчёт с графиками». Агент пишет короткий Python-скрипт, запускает его сам, кладёт результат в папку. Вы читаете готовый файл.

**Как установить Python:**
1. Откройте https://www.python.org/downloads/ → скачайте установщик для своей системы
2. При установке отметьте галочку «Add Python to PATH» (это важно)
3. Готово. Агент дальше всё сделает сам

### Регистрация на GitHub (зачем нужна)

**GitHub** — это бесплатное облако для файлов вашего проекта. Похоже на Google Drive, но с двумя суперспособностями:

1. **История изменений.** Каждое изменение сохраняется. Если агент сломал файл — можно откатиться на любой момент в прошлом одной командой.
2. **Публикация сайтов.** Любой HTML, который агент собрал (портфолио, дайджест, страница-убежище) можно бесплатно выложить в интернет как обычный сайт со ссылкой.

**Как зарегистрироваться:**
1. Откройте https://github.com/signup
2. Придумайте логин, введите почту и пароль
3. Всё. Дальше агент подскажет, как связать вашу папку с GitHub

Без GitHub можно жить, но с ним спокойнее: ничего не потеряется, всё можно откатить, сайты публикуются в один клик.

### Стратегические разговоры

Иногда полезно проговорить решение с кем-то, кто помнит ваш контекст. Агент здесь — не аналитик и не советчик, а зеркало: задаёт вопросы, подсвечивает противоречия, напоминает о том, что вы сами говорили месяц назад.

### Про скилл-хьюманайзер

**Хьюманайзер** — это набор правил, по которым агент вычищает «AI-следы» из текста: шаблонные фразы («в современном мире», «неотъемлемая часть»), любимые слова моделей («вектор», «трансформация», «синергия»), однотипную структуру, канцелярит, пустые обобщения.

Собирается в один файл-скилл. Один раз описываете, что не любите — потом каждый пост / письмо / отчёт агент прогоняет через этот фильтр перед тем, как показать вам.

Как попросить агента собрать хьюманайзер:

> «Собери мне скилл-хьюманайзер: список фраз, слов и оборотов, которые я не хочу видеть в текстах. Начни с базового: канцелярит, "синергия", "вектор развития", "трансформация", "неотъемлемая часть". Дальше буду дополнять по ходу дела. Перед выдачей любого текста прогоняй его через этот скилл.»

Про типовые признаки AI-текста и почему их важно вычищать — в [статье Википедии «Artificial intelligence content detection»](https://en.wikipedia.org/wiki/Artificial_intelligence_content_detection). Оттуда полезно взять список стилистических маркеров и добавить в свой скилл.

Через 2–3 недели скилл заметно снизит ваш «второй заход» на правку — тексты будут сразу выходить чище.

## 13. Пять частых проблем и их решения

### Проблема 1. Агент делает не то, что я прошу

**Причина:** запрос был неоднозначным.

**Решение:** уточните. Не «переделай», а «убери первый абзац, во втором замени слово X на Y, конец оставь».

Ещё лучше: покажите пример «как надо» на другом файле или тексте.

### Проблема 2. Агент забывает мои правила

**Причина:** правило было в разовом разговоре, а не в постоянной памяти (knowledge/AGENTS.md).

**Решение:** скажите: «Это правило важное. Запиши его в AGENTS.md, чтобы всегда помнить». Агент запишет.

### Проблема 3. Слишком дорого / много токенов

**Симптом:** API-счёт растёт, ответы стоят по $1 каждый.

**Решения:**
- Проверьте, не тащит ли агент в каждый ответ огромный AGENTS.md. Сожмите его.
- Используйте бесплатные модели (OpenRouter → free) для мелких задач
- Не ведите в одном чате бесконечную историю — для каждой задачи начинайте новую сессию
- Уберите из knowledge/ ненужные старые записи

### Проблема 4. Агент отвечает медленно

**Причина:** длинный контекст (много файлов) или медленная модель.

**Решения:**
- Не давайте в контекст всё подряд — только нужные файлы
- Попробуйте более быструю модель (в настройках)

### Проблема 5. Агент сломал файл, который я не хотела трогать

**Причина:** был слишком широкий запрос («приведи в порядок все файлы»).

**Решения:**
- Всегда указывайте конкретные файлы
- Держите важные файлы в git (см. Часть IV, GitHub) — можно откатить любое изменение одной командой
- Попросите агента: «покажи, что собираешься менять, до того, как менять»

## 14. Приватность и безопасность

### Чего НЕ давать агенту

- Пароли и логины
- Паспортные данные, номера документов
- Данные банковских карт
- Персональные данные других людей (без их согласия)
- Коммерческие тайны вашего работодателя

### Что делать, если случайно дали

1. Удалите сообщение из истории (если платформа позволяет)
2. Смените пароль / выпустите карту заново
3. Проверьте настройки приватности API (не все провайдеры используют ваши данные для обучения; например, Anthropic — не использует)

### Общее правило

Считайте, что всё, что вы пишете агенту, может быть увидено сотрудниками провайдера. Обычно они не смотрят, но техническая возможность есть.

### API-ключ

- Храните в opencode-настройках, не в открытом виде в файлах
- Если случайно опубликовали в интернете (соцсеть, GitHub) — сразу отзовите и создайте новый
- Раз в 3–6 месяцев меняйте ключ на всякий случай

## 15. Когда НЕ нужен агент

Честный список.

**Не нужен, если:**
- У вас одна разовая задача — используйте обычный чат
- Задача требует лицензированного специалиста (юрист, врач, финансовый советник)
- Нужны 100% точные данные (агент может уверенно ошибаться)
- Вы хотите заменить агентом человеческий контакт (не заменит)

**Точно нужен, если:**
- Задача повторяется еженедельно/ежемесячно
- Копится история и контекст, который важно помнить
- Вы уже описывали одно и то же трём разным чатам — пора сделать одного постоянного агента

## 17. Глоссарий: 15 терминов

| Термин | Что значит | Пример |
|--------|-----------|--------|
| Промпт | Ваше сообщение агенту | «Напиши сопроводительное» |
| Агент | AI с инструкцией и памятью | Карьерный стратег, редактор постов |
| Суб-агент | Специализированный агент внутри проекта | Отдельный агент только для постов |
| Контекст | Всё, что агент знает при ответе | AGENTS.md + файлы проекта |
| Токены | Единицы, за которые платите API | ~750 слов = 1000 токенов |
| API-ключ | Пропуск к AI-модели | sk-ant-api03-XXX... |
| Модель | Конкретный «мозг» AI | Claude Sonnet, GPT-4, DeepSeek |
| .md | Текстовый файл с простой разметкой | AGENTS.md |
| .json | Файл-анкета с данными | config.json |
| Репозиторий | Папка проекта под контролем git | Ваш проект-ассистент |
| Git | Система «отменить» для файлов | Откатить сломанный файл |
| Скилл | Готовая функция / модуль для агента под регулярную задачу | Скилл «дайджест», «хьюманайзер» |
| Команда | «Горячая клавиша» для агента | /start-task, /finish-task |
| Бэклог | Список задач в очереди | docs/BACKLOG.md |

## 18. Куда двигаться дальше

**Ближайшие 2 недели:**

- Освойте базовый цикл: запрос → ответ → правка → «запомни на будущее»
- Соберите одного суб-агента под конкретную задачу
- Дайте 10–15 разных запросов, посмотрите, где агент силён и где ошибается

**Следующий месяц:**

- Добавьте 2–3 суб-агента под разные задачи
- Начните вести knowledge/ — записывайте удачные приёмы
- Попробуйте собрать что-то конкретное: HTML-страницу, регулярный отчёт, дайджест

**Через 2–3 месяца:**

- Вы уже знаете, что вам нужно и что можно спокойно делегировать
- У вас работающая система, которая помогает каждый день
