# Amalgamma v2 — архитектура

## Концепт

Амальгамма — зеркало. Берёт реальную статью (Wikipedia, RSS, любой источник) и отражает её как абстрактную визуальную композицию. Не иллюстрирует, а создаёт визуальный мир: цвета, формы, движение, атмосферу. Отражение ≠ оригинал — в зазоре искусство.

## Принципы

- **Реальные источники.** Только парсинг. Никакой выдумки.
- **Абстракция.** Никакой фигуративности: ни цветов, ни пейзажей, ни иллюстраций.
- **Уникальность.** Каждый артефакт — новый визуальный мир. Цвета, структура, движение — разные.
- **Фулскрин.** Холст = весь экран браузера.
- **Скромный источник.** Только «current inspiration: ...» в углу, едва заметно.
- **Архив для своих.** Все артефакты хранятся в `archive/`. Публичный сайт показывает только текущий.

## Пайплайн

```
cron (каждые 4 часа)
    ↓
1. Wikipedia API → случайная статья
    ↓
2. LLM (DeepSeek/Gemini/OpenRouter):
   «Вот статья. Опиши абстрактную визуальную композицию:
    цвета, формы, движение, атмосферу. Никаких цветов.»
    ↓
3. curator.py генерирует HTML:
   fullscreen, CSS-анимации, слои, частицы, фильтры
    ↓
4. Сохраняет в archive/ → archives/YYYY-MM-DD_HHMM.html
5. index.html = текущий артефакт
6. state.json обновляется (настроение, темы)
```

## Структура файлов

```
amalgamma/
├── .github/workflows/amalgama.yml  # cron: 0 */4 * * *
├── src/
│   ├── curator.py      # оркестратор
│   └── sources.py      # темы и categories (как у Сада)
├── artifacts/
│   └── archive/        # все артефакты (храним, не показываем)
├── state.json          # настроение, темы (аналог souil.json из Сада)
├── index.html          # текущий артефакт (публичный)
├── about.html          # манифест проекта
├── requirements.txt
├── API.txt             # платные ключи (модель:ключ)
├── DGAPIFREE.txt       # бесплатные ключи
├── cost.log            # учёт расходов
├── forage.log          # логи вызовов LLM
└── attic/              # архив старой Амальгаммы v1
```

## Бэкенды LLM (из v1)

- DeepSeek Chat (бесплатный)
- OpenRouter (бесплатные модели)
- Gemini (бесплатный)
- Bothub proxy (платный, $0.50/1M input, $2.00/1M output)

Приоритет: бесплатные → платные. Бюджет: $5/мес.

## HTML-артефакт

- Один самодостаточный HTML-файл
- 100vw × 100vh, overflow: hidden
- CSS-слои: атмосфера (градиенты), формы (div/span), частицы, текстуры (SVG-фильтры), виньетка
- CSS-анимации: медленные, гипнотические, разные длительности
- «current inspiration: Название (год)» — мелко в углу, opacity 0.25–0.35

## Состояние (state.json)

```json
{
  "cycle": 0,
  "mood": "quiet",
  "last_article": "",
  "last_title": "",
  "archive_count": 0
}
```

Минимально. Без сложной «почвы» как у Сада — здесь важнее разнообразие источников, чем эволюция.

## Деплой

GitHub Pages из ветки main. GitHub Actions запускает curator.py по cron. Артефакт пишется в index.html → сразу на сайте.

## Отличия от v1

| | v1 (заморожена) | v2 |
|---|---|---|
| Концепт | AI-личность, рефлексия | Зеркало, отражение |
| Артефакт | Текстовые эссе, swarm | HTML/CSS абстракция |
| Цикл | Каждый час | Каждые 4 часа |
| Harness | 3 LLM-судьи | Нет |
| Архив | wiki/ + chronicles/ + artifacts/ | archive/ (только HTML) |
| Сложность | 1999 строк curator.py | ~400 строк |
| Самонаправление | mutation_engine, anti-stagnation | Нет — источник задаёт направление |
