# Стратегический обзор Pin (品)

*Июль 2026. Автор: NM.ASSISTANT*

---

## Контекст

Pin (品) — ребрендинг проекта Pukuru. Бренд одежды с авторскими принтами существ-фантазёров. Пилот: серия S1-1-2026 — 5 футболок напечатаны. Ресурс: 5–8 ч/нед.

---

## Стратегический анализ

### Позиционирование

| Сильные стороны | Слабые места |
|---|---|
| УТП «тактильная иллюзия» — редкое, не про моду, а про ощущение | Разрыв между позиционированием и продуктом: хлопковая футболка с принтом не создаёт «тактильной иллюзии» |
| Ограниченные квартальные серии (по 5 объектов) — дефицит и коллекционность | Ребрендинг не завершён: папка `docs/pukuru/`, промпты про Pukuru, DNA/Pyramid — уже про Pin |
| Тон «тихий, точный, без восторга» — попадает в уставшую от громких брендов аудиторию | Нет чёрного цвета — ограничивает вариативность (5 SKU) |
| Название 品 — ёмкое, работает и как «изделие», и как pin-булавка | Каналы продаж и продвижения не определены |

### Конкурентная среда

Заявленные конкуренты — фарфоровые броши, эмалевые значки, керамические плакетки (предметы искусства). 
Реально Pin конкурирует на полке с малыми брендами принтованного мерча. 
Разрыв между заявленным и фактическим конкурентным полем надо закрывать либо продуктом (реальная тактильность), либо позиционированием.

### Сценарии развития

| Сценарий | Суть | Риски | Условия успеха |
|---|---|---|---|
| A — «Закрыть разрыв» | Доработать продукт до УТП: тактильная печать (объёмная, с лаком, светоотражающая), нестандартные ткани | Дороже, сложнее, дольше | Найти партнёра по спецпечати, поднять цену, сократить тираж |
| B — «Минимальный бренд» | Принять Pin как авторские футболки с принтами. Убрать «тактильную иллюзию» из УТП | Потеря уникального позиционирования, конкуренция с тысячей мелких брендов | Агрессивный контент, коллаборации, быстрый выпуск |
| C — «Антихрупкий гибрид» | S1 — минимальные футболки (как есть). S2 — тактильный эксперимент (3 шт., спецпечать, цена ×2) | Двойная работа, размытый фокус | Чёткие критерии: какая серия идёт дальше |

**Рекомендация: Сценарий C.** Пилот уже напечатан — продать как Prints (S1). Параллельно готовить S2 как Objects (тактильная серия). Это даёт и деньги сейчас, и проверку главной гипотезы.

## Маркетинговый анализ

### Целевая аудитория (сегменты)

1. **Коллекционеры** — собирают лимитированные вещи. Важны история, номер, шифр серии.
2. **Сознательные минималисты** (25–40) — не носят логотипы, 5–10 вещей в гардеробе, каждая осознанно.
3. **«Искусство на теле»** — креативный класс (дизайнеры, архитекторы, художники). Важен сторителлинг.
4. **Подарочная аудитория** — «другу, у которого всё есть». Работает через упаковку и историю.

### Каналы (приоритет для теста)

1. **Telegram-канал «тихого бренда»** — без продаж, только процесс: эскизы, пробы печати, брак, история поиска. Продажи — через личные сообщения или закрытый бот.
2. **Ярмарка Мастеров** — витрина для сегментов 1 и 4.
3. **Коллаборации** — фотографы, художники, локальные бренды. Футболка Pin в кадре = контент.
4. **Не рекомендовано сейчас:** Ozon/Wildberries — аудитория не совпадает с тоном бренда.

### Ценообразование

- S1 (текущий продукт): 1500–2500₽ — потолок для хлопковой футболки с принтом
- S2 (тактильная печать): 3500–5000₽ — обосновано УТП

### Гипотезы для теста

1. **Упаковка как часть продукта:** если футболка не тактильная — пусть упаковка будет тактильной (крафт, тиснение, номерной ярлык).
2. **Одна футболка = один пост-история:** показать процесс создания конкретной сцены (от конструктора до промпта до печати).
3. **Предзаказ S2:** объявить тактильную серию, собрать предзаказы через Telegram. >10 — делать.

### Метрики

- Количество проданных футболок S1
- Средний чек
- Доля повторных покупателей на S2
- Вопросы от покупателей: «Это настоящее?» (совпадение с позиционированием)

## Ближайшие шаги (следующие 4 недели)

1. **Запустить Telegram-канал** — 2–3 поста в неделю: процесс, эскизы, пробы.
2. **Упаковать S1** — тактильная упаковка, номерные ярлыки, карточки товара.
3. **Выставить на Ярмарку Мастеров** — 5 футболок, измерить спрос.
4. **Начать R&D по S2** — найти партнёра по тактильной печати, собрать 3 предзаказа как тест.
