# Output Contract Template

Шаблон для форматирования вывода research-команд. Адаптирован из last30days-skill.

## BADGE (первая строка, обязательно)

```
🌐 Context Map v{VERSION} · synced {YYYY-MM-DD}
```

Заменяет любой "заголовок от себя". Badge — это титул. Ничего над ним.

## LAWS (не обсуждаются)

### LAW 1 — НЕТ БЛОКА ИСТОЧНИКОВ В КОНЦЕ
Ссылки встроены в текст каждого абзаца. Никаких `Источники:`, `Ссылки:`, `References:` в конце вывода. Ссылки — внутри нарратива.

**Self-check:** просканируй последние 10 строк на `Источники:`, `Ссылки:`, `Sources:`. Если есть — удали.

### LAW 2 — НЕТ ВЫДУМАННЫХ ЗАГОЛОВКОВ
Заголовки разделов только заданные структурой. Никаких «Почему это важно», «Что это значит», «Ключевой вывод». Только: `## 1. Обзорная карта`, `## 2. Поле боя` и т.д.

### LAW 3 — НЕТ ДЛИННЫХ ТИРЕ (—)
Только короткое тире с пробелами: ` - `. Эм-даши (`—`, `–`) — главный маркер AI-слопа.

### LAW 4 — НЕТ ВЛОЖЕННЫХ ПОДЗАГОЛОВКОВ
`###` только в разрешённой структуре (РФ/РБ/Украина/Мир внутри Поля боя). Никаких `### Аналитика`, `### Детали`, `### Выводы`.

### LAW 5 — КАЖДЫЙ ФАКТ — СО ССЫЛКОЙ
В каждом абзаце минимум 1 ссылка `[Название](полный URL)`. Факт без ссылки = не факт.

### LAW 6 — ГОЛОС СООБЩЕСТВА
Если есть Reddit-комментарии, X-посты или Polymarket — вплети 2+ цитаты в нарратив. Не выноси в отдельный блок. Атрибутируй: `u/name`, `@handle`, `Polymarket: X%`.

### LAW 7 — FOOTER PASS-THROUGH
В конце — блок «Как собиралось»: число источников, платформ, ссылка на raw-файл. Если движок выдал footer — передай verbatim.

### LAW 8 — ФОРМАТ ССЫЛОК ПО ХОСТУ
- Claude Code: `[Название](полный URL)` — скрытые ссылки
- GitHub Pages / web: `per Название` — plain label, URL в footer-е

## Self-check перед выводом

- [ ] Badge на первой строке
- [ ] Нет `Источники:` блока в конце
- [ ] Нет выдуманных заголовков (`##`)
- [ ] Нет длинных тире (`—`)
- [ ] Каждый раздел содержит ссылки
- [ ] Community voices вплетены (если есть данные)
- [ ] Footer с метриками есть
- [ ] Формат ссылок соответствует платформе

## Пример: плохо

```
# Аналитика за неделю

Рынок продолжает падать. Это связано с санкциями.
(Источники: rbc.ru, interfax.ru)
```

## Пример: хорошо

```
🌐 Context Map v2.0 · synced 2026-07-10

## 1. Обзорная карта

Рынок продолжает падать третий месяц подряд — курс рубля пробил 95/$, и на r/RussiaEconomics это назвали «тихой девальвацией». На Polymarket вероятность новых санкций выросла до 67%.
```
