# Pre-Flight Template

Перед каждым запуском research-команды (digest, post-writer, career-architect) выполняй этот чеклист.

## Шаг 0: Stale-контекст чек

Проверь, не загрузил ли ты устаревшую версию шаблона/инструкции.
- Если читал файл не из этой сессии — перечитай.
- Если инструкция ссылается на другой файл — проверь, что он актуален.

## Шаг 0.5: Quality Pre-Flight

Классы keyword-ловушек. Если топик попадает в класс — переформулируй или задай 1 уточняющий вопрос.

| Класс | Паттерн | Действие |
|---|---|---|
| 1. Демографический запрос | "подарок мужчине 40 лет", "курсы для новичков" | Уточни хобби/бюджет/контекст |
| 2. Числовая ловушка | число в запросе, которое даёт шум | Убери число из поискового запроса, оставь в контексте |
| 3. Слишком буквально | "как использовать X", "что такое Y" | Переформулируй в дискуссионную форму |
| 4. Одно слово | "зарплаты", "недвижимость", "визы" | Запроси угол: "какой аспект? работа/цены/документы?" |

## Шаг 0.55: Pre-Research Intelligence

Перед запуском скрипта собери:

- [ ] Какие источники сегодня работают? (--diagnose или проверка API)
- [ ] Есть ли ключевые handles/аккаунты для отслеживания? (для person topics)
- [ ] Какие subreddits/коммьюнити релевантны? (категорийные пиры обязательны)
- [ ] Какие Polymarket-маркеты смотреть? (для геополитики/прогнозов)
- [ ] Не устарели ли поисковые запросы? (для cron-задач)

## Pre-Flight Checklist (10 параметров)

Флаги для команд с внешними источниками:

| Флаг | Применять когда |
|---|---|
| `--x-handle` | Person / brand / company topic |
| `--x-related` | Topic has associated entities |
| `--github-user` | Person who ships code |
| `--github-repo` | Product / open-source tool |
| `--subreddits` | Always — each topic has comms |
| `--dedicated-subreddits` | Topic has a home sub |
| `--category-peers` | Topic is in a known category |
| `--polymarket-keywords` | Topic has prediction markets |

## Pre-Flight Gate

Before calling the engine/script, verify:

1. **Источники выбраны** — знаешь какие API/key-читаются
2. **Не keyword trap** — топик переформулирован если надо
3. **Handle-ы разрешены** — handles/subreddits собраны
4. **Допущения названы** — Surface Assumptions выполнены

Если хоть один пункт не пройден — СТОП. Вернись на шаг выше.
