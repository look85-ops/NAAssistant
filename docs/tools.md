# AI-инструменты: обзор и выбор

Дата анализа: 2026-07-06

## Основные (берём в работу)

### Dify
**Что:** Платформа для сборки AI-приложений — визуальные воркфлоу, RAG, агенты, LLMOps.
**Почему:** Python-бэкенд (наш стек), 148k ★, самое зрелое решение. Покрывает все сценарии: от прототипа до продакшна.
**Когда использовать:** Бустер методиста, курсы РЖД, внутренние инструменты, агенты с RAG.
**Ссылка:** https://github.com/langgenius/dify

### free-llm-api-resources
**Что:** Курируемый список 100% бесплатных LLM API с точными лимитами запросов.
**Почему:** OpenRouter, NVIDIA NIM, Google AI Studio, Groq, Cerebras и десятки других — всё в одном месте. Экономит бюджет и время на поиск.
**Когда использовать:** Всегда — как шпаргалка при выборе API под задачу.
**Ссылка:** https://github.com/cheahjs/free-llm-api-resources

## На присмотре

### Sim
**Что:** Визуальный конструктор агентных воркфлоу со встроенным AI Copilot.
**Почему:** 29k ★, очень активный проект (325 релизов). No-code пайплайны.
**Когда рассматривать:** Если понадобится быстро собрать сложный воркфлоу без программирования.
**Ссылка:** https://github.com/simstudioai/sim

### AnythingLLM
**Что:** Self-hosted RAG-платформа «всё в одном»: чат с документами, агенты, управление знаниями.
**Почему:** 62k ★, огромное число поддерживаемых LLM-провайдеров, работает из коробки.
**Когда рассматривать:** Если нужен внутренний чат-инструмент с документацией (методички, курсы, база знаний).
**Ссылка:** https://github.com/Mintplex-Labs/anything-llm
