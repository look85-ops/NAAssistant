## 5. Три правки

### Правка 1: Замена / усиление сессии Манюгиной (8.18)
**Проблема:** единственная сессия с оценкой < 9.0. Для аудитории «резерв начальника службы пути» тема «контроль параметров рельсовой колеи» может быть слишком узкой.
**Действие:** провести A/B — в одной группе оставить Манюгину, в другой заменить на сессию по «системному управлению дистанцией» (более релевантно для ЦА). Сравнить оценки.
**Метрика:** средний балл сессии, NPS по рекомендации.

### Правка 2: Добавить блок «Экономика проекта» к защите
**Проблема:** Непша指出 — «подготовка к защите проекта требовала экономических расчётов, а данных у нас не было».
**Действие:** перед модулем 3 предоставить участникам шаблон экономического обоснования + доступ к данным по нормативам расходов. Или выделить 1 час на разбор расчётов в начале Дня 5.
**Метрика:** доля «соответствовало/превзошло ожидания» в М4.

### Правка 3: Усилить ТБ-брифинг перед промышленными экскурсиями
**Проблема:** Халилов снизил оценку из-за нарушения ТБ на Муромском заводе (очки не выданы при ударных работах).
**Действие:** добавить обязательный ТБ-брифинг перед каждой экскурсией на производство + чек-лист «СИЗ выданы» для организаторов.
**Метрика:** количество замечаний по ТБ в открытых вопросах.

## 6. A/B-гипотеза

**Название:** «Системное управление vs текущая сессия Манюгиной»

**Гипотеза:** Замена сессии Манюгиной Е.А. «Контроль параметров рельсовой колеи» на сессию по «Системному управлению дистанцией пути (планирование, KPI, делегирование)» увеличит средний балл форматов М3 на 0.3+ балла и снизит долю нейтральных оценок.

**Дизайн:**
- Контроль: текущая программа (с Манюгиной)
- Вариант: замена Манюгиной на «Системное управление дистанцией»
- Рандомизация: по группам (если multiple cohorts) или кросс-секционно (первая/вторая половина модуля)
- Валидация прокси: сравнение NPS recommendation, среднего балла форматов, доли «нейтральных» (6–8 баллов)

**Ожидаемый эффект:** средний балл форматов → 9.8+ (с 9.63), доля нейтральных ≤ 5%.

## 7. Инсайты для knowledge/

1. **NPS М3 = 94.1% — лучший показатель среди модулей.** Целевой NPS (9.1) перевыполнен. Ключевой драйвер: качество преподавателей (Мелихов, Залива, Литвинов).
2. **Сессия Манюгиной — единственная точка риска.** Для ЦА «резерв начальника службы пути» тема «контроль рельсовой колеи» менее релевантна, чем «системное управление».
3. **Муромский завод — сильный формат (9.76), но с замечанием по ТБ.** Экскурсии на производство ценятся, но требуют жёсткого контроля безопасности.
4. **Участники готовы к «системному мышлению»:** запросы на планирование, управление временем, KPI, делегирование — это переход от «как делать» к «как управлять».
5. **Данные для экономических расчётов — барьер для защиты проектов.** Нужно обеспечить доступ к нормативным данным до начала проектной работы.
