# NM.ASSISTANT — разделяемый язык

Проект — персональный стратегический ассистент Наташи. Ниже — ключевые термины, чтобы агенты говорили одно и то же.

| Термин | Определение |
|---|---|
| **Амальгамма** | Саморазвивающаяся AI-цивилизация. GitHub Actions, цикл 12ч, репозиторий `look85-ops/amalgamma`. |
| **Бустер методиста** | Цифровой инструмент из 5 модулей для L&D-методологов. GitHub Pages + Netlify. |
| **П+Путь** | «Профессионал+. Путь» — программа повышения квалификации для начальников дистанций пути (ПЧ, ПЧЗ, ПЧГ, ПЧУ). |
| **Академия пути** | Программа развития для резерва начальников службы пути (роль П — дорожный уровень). |
| **Loop Harness** | Модуль верификации цикла Амальгаммы: рубрикатор, LLM-судья, PASS/FAIL, бюджет токенов. |
| **Souil** | «Почво-душа» Digital Garden — файл памяти артефактов с затухающими следами. |
| **Digital Garden** | Репозиторий `look85-ops/digital-garden` — генеративный артефакт с внутренней памятью. |
| **Garden** | Сокращение для Digital Garden. |
| **AOS** | After-Online Survey — анкета обратной связи после обучения. |
| **Eval Owner** | Роль, определяющая «хороший результат» агента и держащая тесты качества. |
| **Exception Handler** | Роль, разбирающая краевые случаи, которые агент зафлагал. |
| **Human-in-the-Loop** | Порог, за которым вывод агента проверяет человек (посты, резюме, стратегия). |
| **Pre-Mortem** | Техника: представить, что решение провалилось — назвать 3 причины. |
| **Pin (品)** | Бренд одежды с авторскими принтами существ-фантазёров. Ранее назывался Pukuru. |
| **P+П** | Сокращение для «Профессионал+. Путь». |

## Соглашения об именах

- Файлы: `kebab-case` для документов (`aos-pilot-plan.md`), `PascalCase` для README-подобных
- ID задач: `F-NNN` (F-001, F-002...)
- Ветки: `f/NNN-kratkoe-nazvanie`
- Коммиты: `[F-NNN] Название фичи`
