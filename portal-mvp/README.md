# L&D без суеты: MVP

Отдельная версия портала для первого запуска.

## Маршрут пользователя

1. Главная → бесплатный материал «Твой первый AI-агент».
2. Бесплатный материал → главный платный гайд по позиционированию.
3. Позиционирование → следующий уровень: большой гайд про AI-агентов.
4. Платный продукт → оплата и выдача PDF через Boosty.

## Что подготовлено

- `index.html` — главная без упоминаний Бустера.
- `materials/first-agent.html` — бесплатный материал.
- `materials/first-agent-print.html` — версия для печати в PDF.
- `products/positioning.html` — главный платный продукт.
- `products/positioning-print.html` — PDF-ориентированная версия гайда.
- `products/agents-guide.html` — лендинг полного гайда.
- `products/agents-guide-print.html` — print-версия лендинга для PDF-обложки/описания.
- Воркбук по онбордингу исключён из MVP. Исходники сохранены в основном `portal`.
- `course/` — бесплатная программа и уроки.
- `PRODUCT_FINAL.md` — зафиксированная продуктовая стратегия.
- `BOOSTY_LINKS.md` — места, где нужно подставить реальные ссылки Boosty.

## Перед публикацией

- Заменить `https://boosty.to/` в трёх местах на конкретную страницу продукта или профиль Boosty.
- Открыть `products/positioning-print.html` в браузере и выбрать «Печать → Сохранить как PDF».
- Проверить, что в PDF кликабельна ссылка `Об авторе курса`.
- Провести один тестовый платеж и проверить выдачу файла через Boosty.

## Эталоны

DOCX-эталоны сохранены рядом с материалами. `first-agent-print.html` и `positioning-print.html` являются самостоятельными версиями для PDF. Большой гайд про AI-агентов остаётся вторым платным продуктом.
