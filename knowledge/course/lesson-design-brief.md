# Дизайн уроков — рекомендации роя (09.2026)

**Агенты:** learning-designer + ui-designer + product-analyst

## Типы контентных блоков
Каждый отличается позицией и типографикой, не контейнером:

| Блок | Визуальный приём |
|---|---|
| **Цель** | Крупно, воздух |
| **Теория** | 720px по центру, чистый текст |
| **Метафора** | Сдвиг влево, курсив, olive left-border 3px |
| **Ключевой инсайт** | olive left-border 4px, чуть жирнее |
| **Практика** | Full-width surface-блок, водяной знак-цифра, нумерованные шаги в olive-кружках |
| **Таблица** | Разреженная, uppercase-заголовки, зебра, olive-подчёркивание заголовков |
| **Код** | olive left-line 2px, mono, без фона |
| **Шпаргалка** | Рамка с чипом «Шпаргалка» |
| **Рефлексия** | Светлый фон (#fafaf8) |
| **Геометрический разделитель** | olive-линия + terracotta-квадрат 12px |

## Структура урока
1. Прогресс-бар (4px olive, sticky top)
2. Hero: водяной знак + тег модуля + заголовок + мета
3. Мини-TOC: горизонтальная навигация с точками
4. Тело: теория → метафора → таблица → практика → шпаргалка → рефлексия
5. Навигация: ← предыдущий / следующий →
6. Футер

## Правила ритма
- Один цветной блок на экран скролла
- Не два плотных экрана подряд
- Не два цветных блока подряд
- Между крупными секциями — геометрический разделитель
- Минимум 60px воздуха до и после метафор/практики

## Анти-паттерны уроков
- ❌ Карточки для разных типов контента
- ❌ Иконки в теле текста
- ❌ Заливка код-блоков фоном
- ❌ Центрирование всего
- ❌ Одинаковые отступы везде

## Продуктовые решения
- Индикатор прогресса, не геймификация
- М4 тизерить только после получения ценности (конец модуля)
- MVP: 6 статических элементов, без бэкенда
