# Лонгрид-дизайн уроков — инсайты (09.2026)

**Агенты:** ui-designer + product-analyst

## Референсы (на кого смотрели)

| Лонгрид | Приём |
|---|---|
| Linear | Трёхколоночная сетка — боковые врезки дают глазу «выпрыгнуть» |
| Stripe docs | Двухколоночная панель — горизонтальное движение глаз |
| The Pudding | Смена фона каждые 2-3 экрана = сигнал «новая глава» |
| Apple Guides | Огромные заголовки + full-width изображения + щедрый воздух |
| Monzo | Водяные знаки-цифры + асимметричные цветные блоки |
| A List Apart | Pull quotes — крупные выдержки для скролла |
| Distill.pub | Margin notes — заметки на полях для двух уровней глубины |

## Новые блоки (добавлены в пилотный урок)

1. **Outcome-список** — в Hero. «После урока вы сможете: ...» — 3-4 конкретных глагола.
2. **Нумерация разделов** — водяные знаки 01-06 за заголовками. Связка с мини-TOC.
3. **Pull quote** — terracotta left-border 3px, крупный italic-текст 28px. 2-3 на урок. «Островок» при скролле.
4. **Margin note** — боковая врезка 220px справа, olive border 1px, muted текст. На мобильных — inline-врезка с фоном surface.
5. **Микро-практика** — 30-секундное действие между блоками теории. Чип «➤ Попробуйте», светлый фон, рамка.
6. **Промежуточный итог** — блок surface после 3-4 концептов. «Итак, вы держите в руках...».
7. **Full-width olive эпизод** — один на урок. Водяной знак, белый текст, главный инсайт.
8. **Открытая петля** — челлендж на завтра в конце. Dashed terracotta-рамка. Создаёт возврат.
9. **Шпаргалка-дубль** — копия внизу страницы «Сохраните себе» + ссылки «Сверьтесь со шпаргалкой ↑» из упражнений.

## Правила ритма (актуализировано)

- Один цветной блок на экран скролла
- Не два плотных экрана подряд
- Не два цветных блока подряд
- После геометрического разделителя — 100px (было 64px, усилено)
- Между крупными секциями — геометрический разделитель + generous whitespace
- Минимум 60px воздуха до и после метафор/практики

## Pre-Mortem лонгрида (почему бросают)

1. «Слишком много теории, я не программист» → микро-практики каждые 2-3 экрана
2. «Практика = 5 вкладок, я устал» → первое действие in-page, остальное — постепенно
3. «Дочитал, закрыл, забыл» → открытая петля + челлендж на завтра

## Приоритет внедрения при тираже

1. Микро-паузы 100px + нумерация разделов (30 мин)
2. Outcome-список в Hero (15 мин)
3. Pull quotes 2-3 на урок (1 час)
4. Промежуточные итоги (30 мин)
5. Full-width olive эпизод (1 час)
6. Margin notes (2 часа)
7. Микро-практики + открытая петля (1.5 часа)

Итого: ~7 часов на шаблон, затем тираж на остальные уроки.
