# Актуализация управляющих презентаций П+Путь / П+Энергия

Методичка и рабочие инструменты для агента, обновляющего PowerPoint-презентации
по новым версиям сценариев (docx с голубым цветом = новый контент).

> Основной подробный документ (workflow, каталог типов, чек-лист):
> `C:\Users\marcenuk\Desktop\Новый проект\docs\course\PPTX_UPDATE_METHODOLOGY.md`

## Ключевые правила

0. **Сценарий = единственный источник актуальной информации.**
   Любое расхождение между сценарием и презентацией трактуется
   в пользу сценария. Презентация подстраивается под сценарий,
   а не наоборот. Если в презентации есть что-то, чего нет в сценарии
   — это устаревший контент, кандидат на скрытие/удаление.

1. **Порядок слайдов = порядок по сценарию.** В сценарии номера слайдов
   могут не совпадать с презентацией (Наташа поправит потом). Смотрим
   не на «Слайд №N» в тексте, а на **последовательность появления
   информации в сценарии**. Если в сценарии сначала идёт вопрос-обсуждение,
   потом теория, потом самостоятельная — так и должны идти слайды.

2. **Что выносим на слайд, а что нет:**
   - **НЕ выносим** блоки `Примечание:` — это методические ремарки
     для ведущего (тайминги, инструкции).
   - **Выносим** содержимое, идущее после метки `Слайд` / `Слайд №N`.
   - **Выносим** реплики после `Преподаватель:` — тоже. Автор потом
     вручную вычистит то, что не должно быть на экране.
   - **Выносим** прямые вопросы участникам (QUESTION_MOD1 / DISCUSS).

3. **Не создавать слайды с нуля.** Только клонирование существующего
   слайда-образца через PowerPoint COM → замена текста → метка.
   См. `pptx_com.py::duplicate_slide`.

4. **Служебные метки:** «Новый» / «Изменено» в правый верхний угол
   (реализовано в `pptx_com.py::add_tag`). Красный, курсив, ~28pt.

5. **Бэкап перед сессией правок** — всегда. Пример имени:
   `..._backup_before_edit.pptx` рядом с оригиналом.

6. **Размер слайда 20 × 12.5" (1440 × 900 pt)** — а не стандартный 16:9.
   Позиционирование текстбоксов и таблиц брать из
   `pres.PageSetup.SlideWidth/SlideHeight`, а не хардкодить.

## Каталог типов слайдов

| Тип | Layout | Пример-эталон в М1Д1 |
|---|---|---|
| COVER | Пустой слайд | 1 |
| SECTION_INTRO | Фирменная рамка №2 | 4 |
| SECTION_HEADER | fbv тема | 11, 45, 67 |
| CONTENT | Только заголовок | 5, 20 (для клонирования — минималистичный), 13, 14 |
| QUESTION_MOD1 | Фирменная рамка №1 (макс) | 12, 16, 17 |
| DISCUSS | Фирменная рамка №1 (макс) | 28, 68, 70 |
| SELFWORK | Фирменная рамка №1 (макс) | 29, 43, 63 |
| BREAK | Фирменная рамка №1 (макс) | 9, 44 |

**Правило подбора шаблона по маркерам в сценарии:**

- «Вопрос участникам:» → **QUESTION_MOD1** (клон #12/#16)
- «Обсудим» / «Поразмышляем» → **DISCUSS** (клон #28)
- «Объединитесь в подгруппы / Рабочая тетрадь: страница X» → **SELFWORK** (клон #29)
- «Кофе-пауза», «ПЕРЕРЫВ 15 МИНУТ» → **BREAK** (клон #44)
- Заголовок раздела дня — **SECTION_HEADER** (клон #45/#67)
- Остальное с содержанием → **CONTENT** (клон #20 — самый чистый)

## Порядок работы над одним модулем (алгоритм)

1. **Извлечь сценарий с цветом:**
   `python word_pages.py` → `scenario_pages.json`.
2. **Отфильтровать нужный диапазон страниц:**
   отредактировать `scenario_report.py` (MAX_PAGE) → получить читаемый TXT
   и `scenario_slide_refs.json`.
3. **Каталогизировать текущую презентацию:**
   `python catalog_types.py` → `catalog.json`.
4. **Составить план правок таблицей** и **согласовать с автором**:
   | # | Действие | Позиция | Тип | Источник |
5. **Сделать бэкап** перед правками.
6. **Правки через PowerPoint COM:**
   - Закрыть все процессы `POWERPNT` перед запуском.
   - Использовать `pptx_com.py`.
   - Именовать новые слайды `MARK_<key>` для гарантированного поиска
     после Move, в конце переименовать в нейтральное имя.
   - Для нескольких вставок подряд — двигать каждый слайд на нужную
     финальную позицию (`MoveTo` считает финальный индекс, не «до»).
7. **Верификация:** открыть в PowerPoint, пройти глазами по помеченным
   слайдам.
8. **Записать в decisions.md** список изменений.

## Гарантии качества

- Файл открывается в PowerPoint (`verify_pptx.py` → `OK`).
- Ни одного слайда с типом `BLANK`, если это не задумано.
- На каждом добавленном/изменённом слайде — метка «Новый»/«Изменено».
- Порядок слайдов соответствует последовательности сценария
  (при расхождении номеров в сценарии — приоритет у сценарной логики,
  номера в сценарии автор поправит вручную).
