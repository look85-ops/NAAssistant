# Поиск слайдов: уникальные строки для COM

При поиске слайдов через COM `find_slide_by_text` используй максимально уникальные строки. Общие фразы («Организация работы хозяйства») могут выдавать первый попавшийся слайд (например, слайд оглавления), а не целевой разделитель.

**Проверенные уникальные строки для Управляющая_презентация_М1Д1_26:**
- Разделитель «Ресурсосберегающие технологии» (слайд 75): `"Комплекс технических, технологических"`
- Разделитель «Планирование и организация путевых работ» (слайд 94): `"\x0bпутевых работ"` (вертикальная табуляция уникальна)
- Парная работа (слайд 79): `"Объединитесь в пары"`
- Шаблон для клонирования: `"Зачем мы здесь?"` (слайд 2)

**Правило:** перед массовым скриптом сначала проверь уникальность строки через python-pptx — `text in full_text` по всем слайдам. Должен быть ровно 1 результат.
