# Уроки по работе с презентацией

## Verbatim text
- Текст на слайдах должен быть **дословно из сценария** — никаких сокращений, перефразирования, добавлений
- Даже очевидные опечатки в сценарии («фактичекский» вместо «фактический») — оставлять как есть
- Не использовать текст из заметок преподавателя (Преподаватель:, Примечание:) как контент слайда
- [NEW] в сценарии = что добавить/изменить; всё остальное уже есть в презентации

## Выбор шаблона
- Если контент не влезает в шаблон — разделить на 2+ слайда, а не уменьшать текст
- Для основного текста использовать шаблоны: 18, 19, 20, 22, 23, 26, 34, 35, 36, 37, 49, 54, 57, 61, 62, 124, 132
- Шаблон подбирать под структуру контента (визуально), а не один для всего
- Можно комбинировать дизайны и создавать свои шаблоны

## Технические баги (исправлено)
- `\x0b` и `\r` в тексте PowerPoint ломают `find_slide_by_text` — всегда использовать короткие уникальные подстроки, не пересекающие line break
- Шаблон дискуссии (3+ вопроса) — слайд 93 (TextBox 20, 21, 22), а не 97
- При клонировании слайда 66 (акцент) остаются TextBox 3 и 4 с оригинальным текстом — нужно чистить
