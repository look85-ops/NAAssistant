(Render → Match → Insert), здесь — рабочая дисциплина вокруг неё.

Раздаточная копия для коллег — `Desktop/Слайды_в_сценарий_алгоритм/`
(`ПРОМПТ_ДЛЯ_АГЕНТА.md`, `ЧЕКЛИСТ_ПРОВЕРКИ.md`, `ПРИМЕР.md`, `1_render.py`,
`2_match.py`, `3_insert.py`).

## Что я должен получить от Наташи ДО начала (иначе строю на песке)

1. **Точный путь к актуальному файлу** — сценарий и презентацию целиком.
   Сверить с датой/именем: если есть `_fin` или свежая дата модификации —
   работаю с ним, а не с устаревшей копией.
2. **Что она уже правила руками** — добавила/удалила слайды, поправила
   нумерацию. Без этого я строю карту с нуля и расхожусь с её ручной правкой.
3. **Что делать с файлом** — перезаписать исходник или копию рядом.
4. **Стоп-правило подтверждено** — «нет явного соответствия → оставить пустым
   и спросить», не угадывать.
5. **Эскиз «до/после»** — один пример (метка → номер + скрин нужного размера),
   чтобы снять неоднозначность по формату (размер 5,5 см, оформление плашки).

## Рабочая дисциплина

- Сначала **отчёт о входе**: сколько меток в сценарии, сколько слайдов в
  презентации — и только потом шаги.
- Номер — по **текстовому соответствию** (TF-IDF + монотонное выравнивание),
  не по счётчику «первая метка → слайд 1».
- Вставка — только `lxml` + `zipfile` на `word/document.xml`. НЕ
  `python-docx.save()` — ломает форматирование.
- Слабые места оставить пустыми и **перечислить отдельным списком**.
- Проверить 5–9 якорей (заголовки разделов) — должны лечь 1:1; не сошлось —
  стоп и объяснить.
- Не трогать media, на которые ссылаются `header*.xml.rels` / `footer*.xml.rels`.

## Как отчитаться

1. Сколько меток получило номер+скрин, сколько оставлено пустыми.
2. Список пустых/спорных мест (номер метки, соседний текст) — для решения.
3. Подтверждение, что файл открывается.
4. Итог: номера не убывают, каждый «Слайд №N» ведёт на верный слайд по тексту.

## Красные флаги (сразу к Наташе, не «чинить» молча)

- Номер «разъехался» по run'ам («Слайд №1615» = «№16»+«15»).
- Номера убывают (20 → 9 → 21).
- Номер вне диапазона числа слайдов (вышел за пределы колоды).
- Скрин под номером показывает явно другой слайд.

## Чему меня научили М3Д1 / М3Д4 (инсайты ядра, повторю не помешает)

- Ключ к качеству — **текстовое сопоставление**, а не порядок.
- Одна грабля: Clark-нотация `'{uri}p'` (без фигурных скобок `iter` вернёт 0).
- При чистке сценария случайно сносила футерный логотип — media чистить только
  по висячим ссылкам из ВСЕХ `.rels`.
- Плотные блоки одинаковых слайдов («ВАША ЗАДАЧА», арт-блок) — всегда показать,
  не угадывать, даже если очень похоже.
