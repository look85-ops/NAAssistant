# Вставка слайдов презентации в сценарий .docx

> **Статус: устарело.** Описанная ниже логика (последовательная вставка
> «маркер N → слайд N») и скрипт `scripts/insert_slides_batch.py` устарели и
> работают плохо. Рабочий принцип 2026-10 — в
> [`scenario-slide-autonumbering.md`](scenario-slide-autonumbering.md).

## Что делать сейчас (в новых диалогах)

Треть файла ниже — историческая запись. Используй алгоритм из
`scenario-slide-autonumbering.md`:

1. **Render** — слайды .pptx → PNG через COM PowerPoint (2500×1406).
2. **Match** — TF-IDF + монотонное выравнивание (DTW) «плашка ↔ слайд» по
   **тексту**, не по номеру.
3. **Insert/Update** — номера и картинки через `lxml` + `zipfile`
   (НЕ `python-docx.save`).

Размер скринов — 5,5 см по высоте (16:9, `wp:extent cx=3519176 cy=1980000`).

## Историческая записка (как НЕ надо)

### Старый принцип (провалился)

1. Слайды вставлялись **последовательно**: первая метка → слайд 1, вторая → 2…
2. Изображение — сразу после абзаца с меткой, новым абзацем.
3. Размер 8.8×5.5 см, по центру.
4. Метка с изображением после себя — пропускается.

**Скрипт:** `scripts/insert_slides_batch.py` — конфиг в шапке (`START/END`,
`DOCX`, `PPTX`, `TDIR`). Считается **неиспользуемым**: пересохранял весь DOCX
через `python-docx.save` (ломал форматирование) и вставлял по порядковому
номеру, а не по текстовому соответствию.

### Уроки провала М1Д4 (2026-09-07)

Ассистент 4 подхода неверно вставлял слайды 41–60; Наташа вставила вручную за
≈3,5 ч. Корневые ошибки:

1. **Не делал карту текстового соответствия** до вставки — вставлял
   последовательно, игнорируя разложенную анимацию и слайды без маркеров.
2. **Не фиксировал manifest входной пары** (хэши, число слайдов, дата) — после
   ручных правок Наташи использовал старые номера/PNG.
3. **Пересохранял весь DOCX через python-docx** — ломал выравнивание/нумерацию
   уже проверенных слайдов.
4. **Не останавливался при первой нестыковке** — продолжал пересобирать.

### Что сработало (правильные паттерны)

- Текстовое сопоставление слайда с контекстом сценария (не с номером).
- Вставка от конца блока внутри смыслового фрагмента.
- Групповая вставка (несколько слайдов у одного маркера — анимация/дискуссия).
- Проверка через Word COM (фактическое отображение), а не только XML.

### Правило на будущее

> Для фазы Б любого модуля: ① manifest пары файлов; ② полная текстовая карта
> «сценарий ↔ слайды»; ③ карта на подтверждение Наташе; ④ вставка только через
> ZIP/XML (не python-docx.save); ⑤ проверка через Word COM; ⑥ стоп при
> нестыковке.
