# Урок: очистка речи преподавателя с готовых слайдов

## Контекст
М3Д1, 275 слайдов. PHASE1 выполнена с ошибкой: на слайды вынесена
речь преподавателя из сценария («Преподаватель:», «Примечание:»,
«Участники записывают...», «мы двигаемся дальше» и т.п.).

## Причина ошибки
При переносе контента из сценария на слайды не фильтровались
строки, адресованные преподавателю, а не участникам. Все строки
сценария (включая реплики) были размещены как текст слайда.

## Правило (дополнение к verbatim-lessons)
**На слайд выносится только то, что видит участник:**
- Определения, факты, таблицы, схемы
- Вопросы для обсуждения (QUESTION_MOD1, DISCUSS)
- Инструкции к заданиям (SELFWORK: «Объединитесь в подгруппы», «Время: N минут»)
- Заголовки разделов

**НЕ выносится:**
- `Преподаватель:` / `Преподаватель ` — реплики для ведущего
- `Примечание:` — методические заметки
- `Если преподаватель...` / `Если нескольким участникам...` — инструкции ведущему
- `Участники записывают/работают...` — описание действий группы
- `Связка-переход:` — методические переходы
- `Цель:` — цели этапа для ведущего
- `Рабочие тетради и ручки...` / `Листы А4...` / `Таймер...` — реквизит
- `давайте обсудим` / `мы двигаемся дальше` / `а теперь...` — речевые переходы

## Метод автоматической очистки
1. Список паттернов речи (regex + подстроки)
2. Для каждого слайда через COM: прочитать текст всех TextBox/Placeholder
3. Удалить строки, совпадающие с паттернами
4. Оставить только контентные строки
5. Если весь текст фигуры — речь → очистить фигуру
6. Сохранить

## Результат на М3Д1
- 186 слайдов исправлено (речь удалена)
- 16 явно проблемных слайдов очищены
- Слайд 10 (речевая фраза) — полностью очищен
- Слайд 158 (инструкции про метрику) — очищен от речи
- Слайды 1–9 не тронуты (уже корректны)

## На будущее
Перед запуском PHASE1-подобной обработки — фильтровать строки
сценария: выносить на слайд только контент, пропускать речевые
и методические строки.
