# Паттерны редактирования презентаций П+Путь (выводы после М1Д1)

## Статистика
- Исходная презентация: 180 слайдов
- После редактуры: 243 слайда (+63)
- Помечено "Новый": 65 слайдов
- Помечено "Изменено": 3 слайда

## Принцип работы
1. **Клонирование** — ни одного слайда с нуля. Все новые слайды созданы дублированием существующего образца + подмена текста. Сохраняет фирменное оформление.
2. **Метки** — "Новый" / "Изменено" в правом верхнем углу, красный италик.
3. **Порядок** — по сценарию, не по номерам слайдов.

## Используемые layout'ы
| Layout | Типы слайдов | Доля |
|---|---|---|
| Только заголовок | CONTENT (основной текст, списки, таблицы) | ~62% (151/243) |
| Фирменная рамка №1 (макс) | QUESTION_MOD1, DISCUSS, SELFWORK, BREAK, FRAMED | ~32% (78/243) |
| fbv тема | SECTION_HEADER | ~5% (11/243) |
| Фирменная рамка №2 | SECTION_INTRO | 1 |
| Титульный слайд | COVER | 1 |
| Пустой слайд | BLANK | 1 (не используется) |

## Каталог типов слайдов
- **SECTION_HEADER** (`fbv тема`) — заголовок раздела
- **CONTENT** (`Только заголовок`) — информационный слайд (текст, таблица, схема)
- **QUESTION_MOD1** (`Фирменная рамка №1 (макс)`) — "Модуль 1. + вопрос" (фронтальный)
- **DISCUSS** (`Фирменная рамка №1 (макс)`) — "Обсудим/Поразмышляем"
- **SELFWORK** (`Фирменная рамка №1 (макс)`) — самостоятельная работа
- **BREAK** (`Фирменная рамка №1 (макс)`) — перерыв
- **QUESTION** (`Фирменная рамка №1 (макс)`) — вопрос без "Модуль 1." (входные)
- **FRAMED** (`Фирменная рамка №1 (макс)`) — прочий контент в рамке

## Паттерны добавления контента
1. **Блоковый** — новые слайды добавляются кластерами (3-17 шт.), а не по одному.
2. **Чередование** — блок CONTENT-слайдов → QUESTION_MOD1 → DISCUSS.
3. **SELFWORK** — всегда с условием + временем + инструкцией.
4. **Таблицы** — через `add_table`, не текстбоксы.
