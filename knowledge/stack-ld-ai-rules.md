# Правила курса L&D x AI

Инсайты и решения, накопленные при разработке учебного стека. Обновляются после каждого модуля.

## Инструменты практики

- **Модуль 1 (техминимум):** PowerShell / терминал. Цель — понять принцип работы API и командной строки.
- **Модуль 2+ (AI):** веб-интерфейсы — OpenRouter Playground, Google AI Studio, ChatGPT/Claude. Цель — управлять моделью, а не программировать запросы. PowerShell был для понимания принципа, не для ежедневной работы.
- Бонусные упражнения «для тех, кто хочет глубже» — опционально, через API/терминал.

## VPN для РФ

- OpenAI (ChatGPT, platform.openai.com) и OpenRouter требуют VPN для доступа из РФ.
- Google AI Studio (https://aistudio.google.com/) часто доступна без VPN для моделей Gemini.
- В каждом уроке — пометка о VPN при первых ссылках на эти сервисы.

## Формат уроков

- `.md` + `.docx` в папке урока. Конвертация: `scripts/convert_md_to_docx.py <input.md> <output.docx>`.
- Теория 20%, практика 80%.
- Обезличенные примеры (без имён, конкретных проектов студентов).
- Бытовые метафоры, без ИТ-жаргона.
