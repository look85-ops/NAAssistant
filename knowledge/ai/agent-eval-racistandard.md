# Стандарт владения агентами (AI RACI / Eval)

**Источник:** Cloud Radix / MIT Technology Review / Deloitte — роли Agent Supervisor, Eval Owner, Exception Handler, Human-in-the-Loop Reviewer.

## Три вопроса к каждому агенту

1. **Кто владелец?** У каждого агента есть фамилия человека, который за него отвечает. Владелец — из функции, потребляющей результат (не IT). IT строит и чинит, владелец отвечает.
2. **Кто определяет «хорошо»?** Eval Owner — единственная по-настоящему новая роль. Держит рубрикатор и набор тестов качества. Остальные роли — переименованный менеджмент.
3. **Кто ловит косяки?** Exception Handler разбирает краевые случаи. Human-in-the-Loop Reviewer аппрувит высокорисковый вывод.

## Как применяем у нас

У нас пока нет отдельного человека под каждую роль. Поэтому:

- **Ты (Наташа) — владелец всех агентов** по умолчанию. Ты же Eval Owner и Exception Handler.
- **Ассистент — Agent Supervisor** (следит за качеством цикла, дрейфом) и **исполнитель**.
- **Порог Human-in-the-Loop:** посты для LinkedIn, изменения резюме, стратегические документы, публичные артефакты.

При создании нового агента (`/new-agent`) обязательно фиксировать:
- Accountable (человек-владелец)
- Eval-критерии (что значит «хороший результат»)
- Порог эскалации (когда звать человека)
