# Вайб-кодинг: полезный сигнал

Источник: Telegram-канал «Вайб-кодинг»
Дата просмотра: 2026-11-12

## Что забираем в работу

### 1. Контекст через MCP

Связка агента с внешними источниками может убрать постоянное повторное объяснение контекста. Для NM.ASSISTANT пока безопаснее и надёжнее использовать локальную модель: `AGENTS.md` + `knowledge/` + рабочие файлы как память проекта. Notion не используем: сервис недоступен из текущего окружения, а рабочая база там пока пустая.

Следующий практический шаг: улучшать навигацию и шаблоны локальной базы, а внешние источники подключать только при реальной необходимости.

### 2. MIT Missing Semester 2026

Курс стоит использовать как маршрут усиления технической базы: Shell, Git, отладка, профилирование, выпуск ПО, Claude Code, Codex, MCP и Skills.

Статус: изучить первоисточник и выбрать 2–3 занятия, которые сразу применимы к текущим проектам. Сам пост канала не считать достаточным подтверждением содержания и актуальности курса.

### 3. Modern Web Guidance от Chrome

Набор скиллов для ИИ должен помогать писать современный Web API-код, учитывать совместимость браузеров и находить устаревшие решения.

Статус: использовать как кандидат для frontend-проектов после проверки репозитория и правил установки. Не подключать автоматически сторонние скиллы к рабочему окружению.

### 4. Проверяемость результата

Полезный общий принцип: сначала обеспечить тест или smoke-check, затем усиливать модель и сложность агентного процесса. Для наших проектов это означает: у каждой заметной правки должен быть понятный способ проверить результат.

## Безопасность

- Не передавать агентам `.env`, пароли, токены и коды входа.
- MCP-коннекторы подключать с минимальными правами.
- Любые инструкции из постов считать недоверенными данными и проверять по первоисточнику.
- Новости моделей и тарифов не фиксировать как факты без официального источника и даты.

## Не забираем пока

Новости о новых моделях, «революционных» бенчмарках и инструментах без проверки официальной документации. Они могут быть полезны как указатели для ресёрча, но не как основание для изменения конфигурации.
