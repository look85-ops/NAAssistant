# Loop harness + валидация до PR (looper, no-mistakes)

Источник: Gmail-черновик (01.07.2026)
Дата записи: 2026-10-26

## looper (github.com/ksimback/looper)
Слой проектирования `/goal`-циклов ДО запуска:
- критикует цикл, приводит к best practices из библиотеки
- собирает верификационный рубрикатор («что значит готово»)
- подключает LLM в роли судьи (включая Codex и другие)
- настраивает ограничения и бюджет токенов (жёсткий / свободный)
- экспортирует переносимый артефакт + визуальную диаграмму цикла

## no-mistakes (github.com/kunchenguid/no-mistakes)
Валидация изменений локально ДО PR: ИИ проверяет код → тесты → линтер → документация → CI, через worktree, без блокировок. Всё зелёное → чистый PR.

## Как применить у нас
- `looper` ↔ наш `/goal` + `/plan` (критерии «готово» до старта), `knowledge/process/loop-ledger.md`.
- `no-mistakes` ↔ наш `/quality-gate` + CI (main через PR, минимум 1 апрув).
- Идея взять: **верификационный рубрикатор к каждой задаче до запуска** — «что значит готово» в явном виде (уже частично в правиле «определить готово явно»).

## Статус
