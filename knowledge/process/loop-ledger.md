# Ledger сессии (журнал циклов)

Адаптировано из loop-engineering (cobusgreyling) — аналог run-ledger.

## Формат

После каждой значимой сессии агент дописывает запись в `logs/session-ledger.md`:

```
## 2026-07-23 — Название задачи (F-NNN)

**Цель:** что хотели сделать
**Факт:** что получилось (или не получилось)
**Итераций:** сколько подходов ушло
**Проблемы:** где буксунули
**Токенов (если доступно):** ~оценка
**Следующий шаг:** что дальше
```

## Когда писать
- После `/finish-task`
- После `/handoff`
- После прерванной сессии (circuit breaker сработал)

## Зачем
1. Накопительная статистика: какие задачи жрут больше всего итераций
2. База для аргумента в портфолио: «внедрила метрики AI-циклов, сократила время на X%»
3. Контекст для новой сессии — не надо вспоминать, что было в прошлый раз

## Связь с существующим
Заменяет разрозненные заметки в knowledge/ и logs/. Не дублирует `logs/decisions.md` (там архитектурные решения) — ledger про сам процесс, не про выбор.
