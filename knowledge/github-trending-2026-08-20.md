## Топ-5 в тему

### volcengine/OpenViking (30.8k ★) — «Контекстная БД для AI-агентов»
Память + знания (RAG) + скиллы = одна виртуальная ФС `viking://`. Ключевые идеи:
- **3 слоя контента:** L0 (резюме, ~100 токенов) → L1 (обзор, ~2k) → L2 (детали, по требованию). Поиск сначала по L0/L1, глубокий слой читается только когда надо.
- **Память из сессий:** после коммита сессии асинхронно извлекает предпочтения и опыт в долгую память.
- **Observable retrieval:** каждый поиск сохраняет траекторию, ошибки можно отлаживать по следу.
- **Бенчмарки:** LoCoMo 24–57% → 80–83% точность памяти, токены −34–91%.
- Лицензия AGPLv3, нужен сервер.

**Зачем нам:** это ровно наш паттерн «прогрессивное раскрытие» (ядро AGENTS.md → knowledge/index.md → детали по задаче), доведённый до продукта. Ставить сервер не нужно — наш mmd-стек дешевле и без инфраструктуры. Подтверждение: направление «память + навыки» — главный тренд, мы в нём.
