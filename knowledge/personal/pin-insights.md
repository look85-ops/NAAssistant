# Pin (品) — извлечённые уроки

## Стратегия
- Разрыв между УТП и продуктом — главный риск. «Тактильная иллюзия» не работает на хлопковой футболке с плоским принтом.
- Ребрендинг нужно проводить до конца, включая файловую структуру и промпты. Незавершённый ребрендинг создаёт путаницу в артефактах.

## Маркетинг
- Для тихого бренда канал должен соответствовать тону: Telegram с process-контентом сильнее, чем маркетплейс.
- Упаковка — часть продукта, когда сам продукт не дотягивает до УТП.
- Предзаказ как gate для новой серии снижает риск провала.

## Процесс
- Анализ проекта перед действиями даёт структуру и приоритеты. Сценарий C (гибрид) снижает риск: продаём что есть, параллельно готовим следующий шаг.
- Ресурс 5–8 ч/нед позволяет вести 2 параллельные задачи по одному проекту (S1 продажа + S2 R&D).
