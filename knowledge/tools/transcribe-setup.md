# Транскрибация аудио/видео (Whisper)

Локальная расшифровка встреч, интервью, записей — без отправки файла во внешние сервисы.

## Что это

`scripts/transcribe/` — утилита на faster-whisper (та же модель Whisper, более лёгкая сборка). Читает аудио/видео, отдаёт текст.

**Результат** — рядом с исходным файлом создаёт два файла:
- `имя.transcript.md` — расшифровка с таймкодами `[00:30–00:59] текст`
- `имя.transcript.txt` — сплошной текст

## Запуск

**Кнопкой (GUI):**
```
scripts/transcribe/Транскрибация.bat
```
Двойной клик → окно: добавить файлы (кнопкой или перетащить), выбрать модель и язык, нажать «Расшифровать».

**Командной строкой** (из корня проекта):
```powershell
py -3 scripts/transcribe/transcribe.py "путь\к\файлу.mp3" [ещё...]
```
Опции: `--model` (tiny|base|small|medium|large-v3), `--language` (ru|en|auto), `--out` (папка), `--no-txt` (не писать txt).

## Модели

| Модель | Скорость (час записи на CPU) | Качество | Когда |
|---|---|---|---|
| tiny/base | ~5–10 мин | слабое, для набросков | черновики, поиск ключевых слов |
| small | ~15–30 мин | среднее | обычные встречи, баланс |
| medium | ~30–60 мин | хорошее | важные встречи, по умолчанию в GUI |
| large-v3 | часы | лучшее | стенограммы для публикации |

Первая загрузка модели качает файл (~1.5 ГБ для medium, разово, нужен интернет). Кэш в `~/.cache/huggingface`.

## Тонкости (грабли, которые я уже собрала)

- **`ffmpeg` обязателен** — Whisper сам аудио не читает. Путь уже в PATH (`C:\Users\marcenuk\AppData\Local\...`). Ставился: `winget install Gyan.FFmpeg`.
- **Python 3.14 + PyAV**: ставить только `av==17.1.0` (у 19.x ломается `faster-whisper`, у более старых нет wheel под 3.14). Если пересоздаёшь venv — `pip install faster-whisper av==17.1.0`.
- **`compute_type="float32"` на CPU** — `int8` выдаёт пустые сегменты. В скрипте уже прописано float32.
- **`vad_filter` выключен** — на этой связке резал результат в ноль.
- **Файл без аудио-потока** (например, видео только с музыкой/без дорожки) → «ничего не распознано». Проверить потоки: `ffprobe -v error -show_entries stream=codec_type -of csv=p=0 "файл"`.
- **Кириллица в выводе консоли** PowerShell ломается (кодировка) — на результат не влияет, файлы пишутся в UTF-8 корректно.

## Окружение

`scripts/transcribe/.venv` — виртуальное окружение, изолировано от системного Python. Пересоздание:
```powershell
py -3 -m venv scripts/transcribe/.venv
scripts/transcribe/.venv/Scripts/python.exe -m pip install faster-whisper av==17.1.0
```

## Сценарии

- **Разобрать встречу с заказчиком** → чуть позже прогоняю на small/medium, читаю `.md` с таймкодами.
- **Интервью для статьи/кейса** → large-v3, потом выжимка решений и договорённостей.
- **Подкаст/лекция** → small хватает для понимания смысла.
