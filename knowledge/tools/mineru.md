# Mineru — PDF/документы → Markdown (OCR)

Источник: Gmail-черновик (01.07.2026). GitHub: opendatalab/mineru (70k+ ⭐)
Дата записи: 2026-10-26

## Что
Опенсорс-конвертер документов в чистый Markdown, локально и приватно:
- текст в правильном порядке
- таблицы в HTML
- формулы в LaTeX
- OCR сканов
- 109 языков
- CLI / Python / веб (mineru.net)

## Зачем нам
Закрывает боль извлечения текста из PDF: `pypdf` не читает сканы и сбоит на сложной вёрстке, `mineru` — с OCR и структурой. Кандидат вместо pypdf в `read_doc.py` / при обработке PDF для конспектов.
