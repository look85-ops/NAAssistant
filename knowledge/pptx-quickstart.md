## СЦЕНАРИЙ 4: Клонировать слайд + заполнить текстом

```python
from pptx_com import open_pptx, duplicate_slide, set_shape_text_by_hint, add_tag, move_slide, save_pres

pres = open_pptx("путь.pptx")
# Клон слайда #20 (CONTENT — чистый образец)
new_idx = duplicate_slide(pres, 20)  # вернёт индекс клона
set_shape_text_by_hint(pres, new_idx, "Заголовок", "Твой новый заголовок")
add_tag(pres, new_idx, "Новый")
move_slide(pres, new_idx, 35)  # переставить на позицию 35
save_pres()
```

**Образцы для клонирования (из М3Д3):**
- Slide 20 = CONTENT (минималистичный, чистый)
- Slide 12 = SELFWORK (с тетрадью и таймером) — клон #16 если есть
- Slide 28 = DISCUSS
- Slide 44 = BREAK (кофе-пауза)
- Slide 3 = SECTION_HEADER («Модуль X. | Y | Работаем с 9:00»)
- Slide 11 = QUESTION («В вашей практике...?»)

## СЦЕНАРИЙ 6: Переупорядочить слайды (ручное перетаскивание = зло)

```python
# 1. Строим карту: target[конечная_позиция] = текущая_позиция
target = {1: 1, 2: 3, 3: 2, ...}  # пример

# 2. Двигаем от КОНЦА к началу
for final_pos in reversed(sorted(target.keys())):
    current = target[final_pos]
    if current != final_pos:
        move_slide(pres, current, final_pos)
```

**Проверено:** 97 слайдов — 30 секунд. Не трогать мышкой.

## ГЛАВНЫЕ ПРАВИЛА (без них скрипты ломаются)

1. **Кириллица в путях**: python-pptx падает с `PackageNotFoundError`. Копировать pptx в `$env:TEMP\opencode\pres.pptx` перед работой.
2. **Бэкап перед правками**: `..._backup_before_edit.pptx`.
3. **Голубые дополнения ДО новых слайдов**: иначе индексы съезжают.
4. **Клон меняет структуру форм**: проверить на тестовом клоне (количество Shapes, текст) → настроить индексы.
5. **Не тегировать всю презентацию**: только реально правленые слайды.
6. **MoveTo — финальный индекс**: `move_slide(pres, from_idx, target_idx)` — target_idx это где слайд ОКАЖЕТСЯ после перемещения.
7. **MoveTo от конца к началу**: иначе уже размещённые сбиваются.
8. **Порядок в сценарии > номера слайдов в сценарии**: если «Слайд №N» стоит не по порядку — следовать логике сценария, а не числам. Наташа номера поправит потом.
9. **АП-дырки не трогаем**: блоки из других модулей (М1Д1, etc.) — Наташа вставляет вручную.
10. **Сценарий — единственный источник истины**: расхождение с презентацией → в пользу сценария.
