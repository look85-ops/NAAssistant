## Программы «Профессионал+» (точные имена)

- **П+Путь (НАША):** `Развитие профессиональных компетенций руководителей хозяйства пути и сооружений. Профессионал+.Путь`
- **П+Движение (чужая, для проверки):** `Развитие профессиональных компетенций руководителей блока управления движением "Профессионал+. Движение"`
- **П+Тяга (чужая, для проверки):** `Развитие профессиональных компетенций руководителей локомотивного хозяйства. Профессионал+. Тяга`

Работаем только по **П+Путь**. П+Движение и П+Тяга — чужие программы, но наши анкеты/преподаватели **иногда ошибочно падают туда**. Поэтому при каждом прогоне: сначала ищем в П+Путь; если нужного вуза/преподавателей нет — **проверяем П+Движение и П+Тяга** (вдруг они там).

## Как определить, какие вузы в выгрузке

В выгрузке **нет колонки «вуз»**. Вуз определяем по паре преподавателей:
- смотрим уникальные значения `ФИО преподавателя` внутри отфильтрованной программы+даты;
- сопоставляем с историей (см. маппинг);
- вуз без пары преподавателей → его анкеты просто не пришли в этой выгрузке (не ошибка, ждём).

**Fallback-проверка «чужих» программ:** если у нас в П+Путь не хватает вуза или пары преподавателей — ищем их `ФИО преподавателя` (и вуз-маркеры) по **всей выгрузке**, включая П+Движение и П+Тяга. Преподаватели из маппинга П+Путь (Акимов/Севостьянов, Опацких/Коржакова, Парахненко/Бишлер, Атапин/Дорофеев, Чернецкая/Насников/Габитов, Манюгина/Гринь/Зайцев, Петерс/Вальцева/Гильмутдинов) — маркеры «наших» вузов. Если нашли их в чужой программе — переноcим оттуда строки в П+Путь (сообщить Наташе, что анкеты упали не туда).

## Шаги процесса

1. **Отфильтровать:** `Название программы == <П+Путь>` И `Дата == <дата обучения>` (например `2026-10-23`).
   - «Дата» = дата заполнения анкеты; «Дата обучения» = дата занятия. Фильтруем по `Дата`. Поздние анкеты (заполнены 25–26 числа про занятие 23-го) — **не включаем** (остаются за фильтром). При неоднозначности — спросить, нужны ли поздние.
2. **Убрать пустые строки:** строки, где `ФИО слушателя` пусто И все оценки пустые, — это зарегистрированные, но не ответившие. Оставляем только строки с непустым `ФИО слушателя`.
3. **Нарезать по вузам** (по `ФИО преподавателя` из маппинга), взять **14 колонок** в этом порядке:
   `Название программы, Название учебного тематического блока, Формат проведения, Номер группы, Дата обучения, ФИО слушателя, ФИО преподавателя, Готовы ли Вы рекомендовать данное обучение?, Преподаватель понятно излагает материал, Во время обучения Вы чувствовали себя включенным в работу, Преподаватель качественно и полно отвечает на вопросы участников, Обучение было для меня интересным, Знания и навыки, полученные в ходе обучения, имеют практическую применимость, Напишите Ваши пожелания по улучшению обучения:`
4. **Сохранить** в папки вузов с именем `АОС_<ВУЗ>_П+Путь_<ДД.ММ>.xlsx`.
5. **Собрать свод** (структура ниже).
6. **Обновить `Свод_ВУЗЫ_П_2026_<N> полугодие.xlsx`** — заполнить очередной модуль.

## 6 вопросов для расчёта

1. Готовы ли Вы рекомендовать данное обучение?
2. Преподаватель понятно излагает материал
3. Во время обучения Вы чувствовали себя включенным в работу
4. Преподаватель качественно и полно отвечает на вопросы участников
5. Обучение было для меня интересным
6. Знания и навыки, полученные в ходе обучения, имеют практическую применимость

## Формула «Оценка за модуль»

- По каждому из 6 вопросов — среднее по **непустым** ответам (пустые НЕ считаем, не зануляем).
- **Оценка за модуль = среднее из 6 средних по вопросам** (round до 6 знаков).
- Среднее по вузу (в «Своде») = среднее оценок всех пройденных модулей.

Оценки 1–10. Пустые клетки — просто пропуск, не 0.

## Структура свода (листы)

1. **«Свод по ВУЗАм»** — строки: 7 вузов по порядку `МИИТ, СГУПС, ДВГУПС, РГУПС, ПривГУПС, УрГУПС, ИрГУПС` + итоговая строка. Рядом — среднее по вузу.
2. **«<ВУЗ>»** (7 листов) — шапка: `№ группы, Преподаватель, Модуль программы, Оценка за модуль, Среднее по группе, Среднее по всем группам`. Далее Группа 1 (Модуль 1–4) и Группа 2 (Модуль 1–4).
3. **«<ВУЗ>_ОЦЕНКИ»** (7 листов) — шапка из 6 вопросов; блок по дате: строка с датой + первая анкета, дальше оценки слушателей построчно, внизу строка средних (6 средних по вопросам + оценка за модуль).

Имена листов с суффиксом „ОЦЕНКИ“ хранят пробелы как в эталоне (`МИИТ_ОЦЕНКИ `, `ДВГУПС_ОЦЕНКИ ` — с хвостовым пробелом, остальные без). Для II полугодия — новый файл, не трогаем I.

## Технические детали

- **Python:** `C:\Users\marcenuk\AppData\Local\Python\bin\python.exe` (3.14.4, есть pandas + openpyxl).
  - `python ...` из PATH ведёт на заглушку Windows Store — всегда вызывать **полный путь**.
- Писать xlsx через `pandas.to_excel` (простые файлы) или `openpyxl` (свод с датами/структурой).
- Кириллицу в консоли не читает: результаты/проверки пишем во временный `.txt` (UTF-8) и читаем его, а не `print`.
- **Файлы .xlsm** (как график обучения) openpyxl не открывает — падает на stylesheet. Читать вручную через `zipfile`: `xl/sharedStrings.xml` + `xl/worksheets/*.xml`, даты там excel-сериалами (пересчёт: `datetime(1899,12,30) + timedelta(days=serial)`).
