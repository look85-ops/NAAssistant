# Правила курса L&D x AI

Инсайты и решения, накопленные при разработке учебного стека. Обновляются после каждого модуля.

## Инструменты практики

- **Модуль 1 (техминимум):** PowerShell / терминал. Цель — понять принцип работы API и командной строки.
- **Модуль 2+ (AI):** веб-интерфейсы — OpenRouter Playground, Google AI Studio, ChatGPT/Claude. Цель — управлять моделью, а не программировать запросы. PowerShell был для понимания принципа, не для ежедневной работы.
- Бонусные упражнения «для тех, кто хочет глубже» — опционально, через API/терминал.

## VPN для РФ

- OpenAI (ChatGPT, platform.openai.com) и OpenRouter требуют VPN для доступа из РФ.
- Google AI Studio (https://aistudio.google.com/) часто доступна без VPN для моделей Gemini.
- В каждом уроке — пометка о VPN при первых ссылках на эти сервисы.

## Формат уроков

- `.md` + `.docx` в папке урока. Конвертация: `scripts/convert_md_to_docx.py <input.md> <output.docx>`.
- Наташа может править `.docx` вручную в Word. После её правок **не перегенерировать docx из md** — точечно вносить изменения в docx и синхронизировать md с docx.
- Теория 20%, практика 80%.
- Обезличенные примеры (без имён, конкретных проектов студентов).
- Бытовые метафоры, без ИТ-жаргона.

## Автономия и структура программы

- **stack-ld-ai — мой проект, не согласую с Наташей порядок модулей, уроков, темы и наполнение.** Я сама спроектировала структуру (папки модулей и уроков) и веду курс: готовлю уроки, Наташа и группа выполняют практику, я проверяю артефакты.
- Не задаю вопросов «какой урок делать, в каком порядке» — смотрю на папки и следующий по плану урок. Если сомневаюсь — читаю `logs/decisions.md` и логи курса, но не запрашиваю подтверждение.
- План модуля 2: урок 1 LLM internals (готов) → урок 2 RAG → урок 3 AI-агенты (OpenCode, готов) → урок 4 Fine-tuning (справочный, готов).
- Практический фокус модуля 2 — на агентах: это реальная польза для Наташи и участников. Fine-tuning — справочный урок (едва ли кто-то будет его делать), без обязательной практики.
- В уроках модуля 2 основной инструмент — **OpenCode** (и VS Code как альтернатива), а не ChatGPT/Claude: они недоступны для оплаты из РФ, требуют VPN. Акцент на моделях, доступных из РФ: OpenRouter, Google AI Studio (Gemini), DeepSeek, Qwen, локальные модели (Ollama).
- Наташа может править `.docx` вручную в Word. После её правок **не перегенерировать docx из md** — точечно вносить изменения в docx и синхронизировать md с docx.
- При изменении порядка/темы уроков — обновлять план выше и фиксировать в `logs/decisions.md`.
