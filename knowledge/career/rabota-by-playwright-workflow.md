# Мониторинг и отклик на rabota.by через Playwright

## Почему Playwright, а не requests
rabota.by — JS-рендеринг, старый скрипт на regex может не видеть часть вакансий. Playwright даёт полный DOM после загрузки JS. Плюс позволяет заполнять формы отклика.

## Инструмент
Playwright MCP в opencode. Браузер Chromium, headless. Команды: `playwright_browser_navigate`, `playwright_browser_snapshot`, `playwright_browser_click`, `playwright_browser_type`, `playwright_browser_fill_form`.

## Алгоритм мониторинга rabota.by

### Шаг 1. Открыть поиск
URL: `https://rabota.by/search/vacancy?text=обучение+и+развитие+персонала&area=1002&items_on_page=100`

Ключевые слова для поиска (по приоритету):
1. "обучение и развитие персонала"
2. "менеджер по обучению"
3. "специалист по обучению"
4. "корпоративное обучение"
5. "бизнес-тренер"
6. "T&D" OR "training and development"
7. "L&D"
8. "методист"
9. "онбординг"
10. "edtech"

Фильтры: area=1002 (Минск), items_on_page=100. Без фильтра по графику (не все вакансии с удалёнкой).

### Шаг 2. Снять снепшот страницы
`playwright_browser_snapshot` — получить accessibility-дерево со всеми карточками вакансий.

### Шаг 3. Спарсить вакансии
Из снепшота вытащить:
- Название (заголовок)
- Компания
- Зарплата (если указана)
- Ссылка на вакансию
- Краткое описание/требования

### Шаг 4. Отфильтровать
- Только rabota.by-хостинг (не hh.ru кросс-листинг)
- Исключить: HR-generalist (ТК, кадры, 1С), склад/розница, продажи кухонь/мебели
- Исключить: «Директор по организационному развитию»
- Проверить на релевантность L&D/обучению

### Шаг 5. Сохранить результат
В `career/market/monitor_{date}.md` — markdown-отчёт.

## Алгоритм отклика на rabota.by

### Шаг 1. Открыть страницу вакансии
Перейти по ссылке конкретной вакансии.

### Шаг 2. Нажать «Откликнуться»
Кнопка обычно с текстом «Откликнуться» или «Respond».

### Шаг 3. Заполнить форму отклика
Поля:
- Сопроводительное письмо — 800-1000 знаков по шаблону из `career/cover_letters/rabota-by-response.md`
- Резюме — прикрепить PDF (беларусская версия)

### Шаг 4. Отправить
Нажать «Отправить» / «Submit».

### Шаг 5. Записать результат
В `logs/decisions.md`: дата, компания, должность, статус.

## Правила текста (из knowledge/rabota-by-response-rules.md)
- «10+ лет в L&D» (не 17)
- БГАИ не упоминать
- Не писать про AI-ассистента — это письмо от Наташи
- Только факты, не придумывать
- AOS Analyzer → «система аналитики обратной связи»
- Переезд: «с конца ноября — в Минске (переезд по семейным обстоятельствам)»
- Текущая работа — настоящее время; завершённые роли — прошедшее
- Резюме: «Менеджер по обучению и развитию персонала» (Минск, 4 500 BYN)
- Сопроводительное: «вы ищете X → у меня Y → результат Z»
