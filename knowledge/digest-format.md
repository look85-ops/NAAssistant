# Формат дайджеста «Радар L&D» (пересобран 2026-08-20)

Канонический формат выпуска. Собирать строго по нему, не изобретая заново.

> Название «L&D × AI» закреплено за учебной программой (`stack-ld-ai/`). Публичный дайджест называется **«Радар L&D»** — не путать.

## Ядро концепции

- Еженедельный дайджест об обучении, ИИ и карьере. Для L&D-специалистов и HR-руководителей: тренды, инструменты, цифры.
- «Карта контекста», а не свалка новостей: даёт ориентацию за 10 минут.
- Баланс тем: не только ИИ — тренды обучения, методики, инструменты (узкий фокус на ИИ формирует «дополнительную усталость»).
- Публикуется на GitHub Pages (`career/posts/digest/digest-{YYYY-MM-DD}.html`), ТГ/LinkedIn — по факту.

## Дизайн-голос «Тихая уверенность»

Editorial-минимализм (New Yorker) + аналитическая сетка (data-journalism). Сдержанный, дорогой, интеллектуальный.

- Бумага `#F4F0E8`, чернила `#1E1D1B`
- Акцент `#A6332E` (сургучный красный), вторичный `#2B3A55` (глубокий синий)
- Шрифты: **Literata** (заголовки/цитаты, serif), **Golos Text** (текст), **JetBrains Mono** (метки, номера, статусы, фор-ум)
- Подключение через Google Fonts

### Обложка
- Мастхед: `Радар L&D · weekly context map` слева, `№ NN` справа (JetBrains Mono, капс, разрядка, muted)
- Фор-ум строка под мастхедом: «Еженедельный дайджест об обучении, ИИ и карьере. Для L&D-специалистов и HR-руководителей: тренды, инструменты, цифры.» — тот же шрифт, цвета шапки, но светлее (`#8A8579`)
- issue-no (JetBrains Mono, акцент), H1 (Literata 40px), lede (18px, 1-2 предложения с `<strong>`-якорями)
- НЕ добавлять date-line-приписки типа «ориентация за 10 минут» и «без рекламы»

### Секции
Номер (01…) · название (serif-заголовком) + running-подпись справа (JetBrains Mono, muted).

1. **01 · Карта недели** — 3-4 сигнала. На каждый: H3 (Literata 21px), meta-строка «источник · дата» (JetBrains Mono), 1-2 абзаца фактов, строка `Что это меняет:` с красной плашкой слева.
2. **02 · Радар трендов** — таблица-список статусов: усиливается (красная точка) / появился (чёрная) / плато (синяя) / угасает (серая). Повторы тем во времени = фича («продолжение наблюдения»), не дублирование.
3. **03 · Сквозная мысль** — 1 крупная цитата-вывод недели (Literata italic 24px, красная линия слева). Это главный месседж выпуска.
4. **04 · Инструмент недели** — ТОЛЬКО инструмент (не «статья/промпт/книга»). Блок-врезка с рамкой navy на тёмном фоне. После «Как применить» — строка «Связь с выводом недели»: инструмент поддерживает сквозную мысль, а не живёт отдельно.
5. **05 · Рынок/Карьера** — международный фон (вакансии, тренды найма), коротко. Рынок РБ — НЕ для публичного выпуска (это персональный материал).

Футер: `Радар L&D · вып. NN · дата` (JetBrains Mono, muted). Без «оглавление · источники».

## Анти-паттерны

- Без эмодзи, градиентов, глейма, теней на карточках, шаблонных hero-лендингов
- Без канцелярита и AI-клише (см. хьюманайзер): «в рамках», «осуществляется», «трансформация», «синергия», «unlock potential»
- Никакого контента без подтверждения из веба — инструменты/цифры только из проверенных источников, иначе блок пропускается
- Один акцент-цвет на экран максимум
