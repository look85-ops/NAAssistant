## Принцип работы

При выборе шаблона:
1. Посмотри на объём и структуру контента
2. Выбери шаблон, который визуально подходит
3. Используй `find_slide_by_text(pres, search_string)` для поиска
4. Клонируй через `duplicate_slide`, затем `move_slide`
5. Замени текст через `replace_shape_by_first_line(slide, hint, new_text)`

Если контент не влезает — не пиши мельче, а раздели на 2+ слайда.

Можно комбинировать дизайны — изменять, добавлять элементы, создавать свои шаблоны.
