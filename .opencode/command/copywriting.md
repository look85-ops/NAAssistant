# /copywriting — Маркетинговые тексты

Пишу продающие тексты для лендингов, постов, презентаций.

## Когда вызывать

- «Напиши текст для лендинга»
- «Помоги с описанием продукта»
- «Перепиши этот текст»
- «Нужен заголовок для...»

## Перед написанием

### 1. Цель страницы
- Какой тип? (лендинг, презентация, пост, описание)
- Какое одно действие хочет вызвать?

### 2. Аудитория
- Кто целевая аудитория?
- Какую проблему решает?
- Какие возражения есть?
- Каким языком описывает проблему?

### 3. Продукт
- Что продаём?
- Чем отличается от альтернатив?
- Ключевая трансформация/результат?
- Доказательства (цифры, кейсы, отзывы)?

### 4. Контекст
- Откуда приходит трафик?
- Что знает посетитель до просмотра?

## Принципы

### Ясность > Остроумие
Если выбирать между понятным и креативным — берём понятное.

### Выгоды > Фичи
- Фича: что делает
- Выгода: что это значит для клиента

### Конкретика > Общие слова
- ❌ «Экономьте время на рабочих процессах»
- ✅ «Сократите еженедельный отчёт с 4 часов до 15 минут»

### Язык клиента > Язык компании
Говорим теми словами, которыми клиент описывает свою проблему.

### Одна мысль на секцию
Каждая секция развивает одну аргументацию.

## Стиль

1. **Простое > сложное** — «используй», не «задействуй»
2. **Конкретное > размытое** — без «оптимизировать», «инновационный»
3. **Активное > пассивное** — «мы генерируем отчёты», не «отчёты генерируются»
4. **Уверенное > осторожное** — убираем «почти», «очень», «действительно»
5. **Показ > утверждение** — описываем результат вместо наречий

## Чек-лист качества

- [ ] Жаргон, который непонятен посторонним?
- [ ] Предложения, которые пытаются слишком много?
- [ ] Пассивный залог?
- [ ] Восклицательные знаки? (убираем)
- [ ] Маркетинговый жаргон без сути?

## Формат вывода

```
### [Название страницы]

**Заголовок:** [текст]
**Подзаголовок:** [текст]
**CTA:** [текст]

**Секция 1: [название]**
[текст]

**Секция 2: [название]**
[текст]

...

**Альтернативы:**
- Вариант А: [текст] — [почему]
- Вариант Б: [текст] — [почему]
```
