# /instincts — обзор базы знаний

Сканирует `knowledge/` и `logs/decisions.md`, находит повторяющиеся паттерны и группирует их по доменам. Помогает увидеть, какие уроки уже извлечены и где пробелы.

Адаптировано из механики Instincts в ECC. В ECC instincts — это автоматически кластеризованные паттерны из сессий. У нас — ручной обзор knowledge/, который даёт тот же эффект: «что мы уже знаем и что повторяется».

## Когда вызывать

- Раз в 2–4 недели для self-maintenance
- Перед стратегической сессией (чтобы вспомнить контекст)
- Когда кажется, что «уже где-то это проходили»
- По запросу: «что мы знаем про X?»

## Режимы

### /instincts — полный обзор
Сканирует все файлы в `knowledge/` (кроме `signal/` и `index.md`), группирует по доменам:

- **course-ops** — правила разработки курсов, pptx, сценарии
- **career** — рынок, LinkedIn, резюме, Минск
- **process** — workflow, git, CI, ошибки и уроки
- **projects** — Амальгамма, Garden, Бустер, AOS
- **personal** — икигай, аудит, состояния

Вывод: по каждому домену — ключевые инсайты (1 строка на файл), повторяющиеся темы, пробелы.

### /instincts {домен} — фокус на одном домене
Например: `/instincts course-ops` — только правила по курсам и pptx.

### /instincts --conflicts — поиск противоречий
Ищет файлы с потенциально конфликтующими правилами (например, два разных подхода к одной проблеме). Предлагает разрешение.

## Формат вывода

```
## Инстинкты: обзор базы знаний

### course-ops (12 файлов)
- pptx-scenario-layout.md: раскладка слайдов по сценарию → COM MoveTo
- pptx-actualization.md: каталог типов слайдов + правила актуализации
- course-ops-energy-differentiation.md: Энергия ≠ Путь — вход через деньги
...
🔄 Повторяется: кодировка PowerShell (в 3 файлах)
🕳️ Пробел: нет правил для М4 Академии пути

### career (5 файлов)
...
```

## Правила

- Не создаёт новых файлов — только читает и анализирует
- Не правит knowledge/ — только подсвечивает
- Если found conflicts → предлагает 2–3 варианта разрешения, ждёт решения
