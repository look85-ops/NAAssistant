Modern Web Guidance from Chrome Developers. Covers: modern CSS (anchor positioning, popover API, container queries, view transitions), HTML standards (<dialog>, <details>, inert), performance (INP, LCP, CLS, long tasks), accessibility (WCAG, ARIA), security (CSP, WebAuthn, passkeys). Framework-agnostic best practices for production web apps. Install: npx modern-web-guidance@latest install. See https://developer.chrome.com/docs/modern-web-guidance
