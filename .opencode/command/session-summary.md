# /session-summary — сохранить саммари сессии в транскрипт

Генерирует структурированное саммари текущей сессии/блока задач и сохраняет в `logs/transcripts/`.  
Триггер — простая речь: «запиши про X», «сохрани контекст», «это важно». Команда `/session-summary` — запасной вариант.

## Процесс

1. **Оценить сессию по критериям** (AGENTS.md → Knowledge Ops → Transcript-worthy).  
   Не тянет → сказать: «Не тянет на транскрипт, хватит строки в decisions.md».

2. **Сгенерировать саммари:**

```markdown
# [Дата] — [Тема]

**Контекст:** с чего начали, что было на входе
**Ключевые решения:** что решили, почему (1-3 пункта)
**Артефакты:** что создали/изменили (файлы, ссылки)
**Tacit knowledge:** что поняли между строк — нюансы, интуиция, неочевидные связи
```

3. **Показать Наташе** — «Сохраняем?»

4. **По подтверждению** → `logs/transcripts/YYYY-MM-DD_тема.md` + обновить `knowledge/index.md` при новой теме.

## Когда срабатывает

- Наташа говорит «запиши», «сохрани контекст», «это важно» — обычными словами
- Ассистент сам предлагает после transcript-worthy сессии

## Guardrails

- Не каждый чих — только transcript-worthy
- Tacit knowledge — самое ценное поле; нет его → возможно, транскрипт не нужен
- Пишется после подтверждения Наташи (🟡)
