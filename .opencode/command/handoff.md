# /handoff

Компактная передача контекста текущей сессии — чтобы другой агент или следующая сессия продолжили без потерь.

## Когда вызывать

- Перед завершением сессии
- При передаче задачи другому агенту
- При сложной задаче, которую не успеваешь закончить за одну сессию

## Формат вывода

Агент собирает handoff-документ в следующей структуре:

```
## Handoff: YYYY-MM-DD HH:MM

### Контекст сессии
{что делали, какие файлы трогали, какие решения приняли}

### Текущая задача
{ID задачи, статус, что сделано, что осталось}

### Блокеры
{что мешает продолжить, какие вопросы открыты}

### Ключевые решения
{зафиксированные архитектурные/стратегические решения}

### Следующие шаги
{конкретные действия для продолжения}
```

## Куда сохранять

По умолчанию — в `logs/handoffs/handoff-YYYY-MM-DD-HHmm.md`.

Если директории нет — создать.
