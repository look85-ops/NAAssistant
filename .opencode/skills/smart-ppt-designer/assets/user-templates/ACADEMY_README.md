# Референсы Академии пути

Локальная коллекция материалов, выданных участникам:

- `АП_шаблон презентации_работа в межмодуле.pptx` — основной шаблон;
- `Иконки (Slidesgo) (1).pptx` — библиотека иконок;
- `Иконки для бизнеса.pptx` — дополнительная библиотека;
- `Гайд Visme.pdf` — методический референс по визуальной подаче.

Основной источник стиля: шаблон Академии. Иконки не являются обязательными: использовать только при смысловой необходимости и не смешивать разные визуальные стили на одном слайде.

Политика верстки: если исходный слайд перегружен, увеличивать число слайдов. Не уменьшать основной текст ниже 12 pt без отдельного согласования.
