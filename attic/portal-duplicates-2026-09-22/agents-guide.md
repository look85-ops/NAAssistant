# agents.md — инструкция для много-агентной системы

> Читать после того, как настроил первого агента (soul.md). Здесь — как собрать команду.

---

## Когда одного агента мало

Один агент = одна роль. Если у тебя несколько повторяющихся задач — делай отдельных агентов.

Пример: методист-агент (проектирует курсы) + редактор-агент (вычитывает тексты) + аналитик-агент (считает метрики опросов).

## Как прописать агента

Каждый агент — это soul.md-файл. Размести их так:

```
project/
├── agents/
│   ├── methodist.soul.md      # Агент-методист
│   ├── editor.soul.md         # Агент-редактор
│   └── analyst.soul.md        # Агент-аналитик
├── knowledge/
├── logs/
└── AGENTS.md                  # Общие правила для всех
```

## AGENTS.md — общие правила

В корне проекта создай файл AGENTS.md. Он описывает общие договорённости: стиль, запреты, структуру папок.

Не надо дублировать это в каждом soul.md. AGENTS.md — для правил, soul.md — для роли.

```
# AGENTS.md

## Общие правила
- Стиль: коротко, без канцелярита, объяснять сложное через бытовые метафоры.
- Все ответы — на русском.
- Перед важными изменениями — спрашивать подтверждение.

## Структура
- knowledge/ — база знаний и инсайты
- logs/ — журнал решений
- agents/ — инструкции агентов
```

## Как агенты работают вместе

**Цепочка:** агент 1 делает → агент 2 проверяет → агент 3 упаковывает.

Пример для L&D:
1. methodist-agent: «Спроектируй структуру 2-дневного тренинга по [тема]»
2. editor-agent: «Проверь текст на канцелярит и длинные предложения»
3. analyst-agent: «Разбери обратную связь участников — выдели 3 паттерна»

**Параллельно:** агенты не мешают друг другу — работают в разных ветках/задачах.

## Как обучать агентов

- Каждый раз, когда агент сделал хорошо → скажи ему об этом. Он запомнит.
- Каждый раз, когда ошибся → объясни почему. Он перестанет так делать.
- Раз в неделю → перечитай soul.md. Что устарело? Что добавить?
- Хороший агент — это агент с историей. Не удаляй старые версии soul.md — храни в `agents/archive/`.

## Типичные ошибки

- **Один агент на всё** — универсальный помощник хуже трёх специализированных.
- **Нет границ** — агент без «никогда» начнёт придумывать цифры и давать советы.
- **Нет логов** — через месяц не вспомнишь, какое решение приняли и почему.
- **Идеальный soul.md с первого раза** — не пиши идеально, набросай и правь после тестов.
