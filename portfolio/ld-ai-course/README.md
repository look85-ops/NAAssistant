# L&D без суеты: MVP

Отдельная версия портала для первого запуска.

## Маршрут пользователя

1. Главная → бесплатный материал «Твой первый AI-агент».
2. Бесплатный материал → открытая программа курса.
3. Открытые уроки → практические артефакты и дальнейшее знакомство с автором.

## Что подготовлено

- `index.html` — главная без упоминаний Бустера.
- `materials/first-agent.html` — бесплатный материал.
- `materials/first-agent-print.html` — источник PDF-версии бесплатного материала.
- Платные продукты в этой витрине отключены. Исходники остались в основном `portal-mvp`.
- Воркбук по онбордингу исключён из MVP. Исходники сохранены в основном `portal`.
- `course/` — бесплатная программа и уроки.
- `PRODUCT_FINAL.md` — зафиксированная продуктовая стратегия.
- `BOOSTY_LINKS.md` — места, где нужно подставить реальные ссылки Boosty.

## Перед публикацией

- Открыть `course/index.html` и проверить переходы по всем открытым урокам.
- Открыть витрину с телефона и проверить читаемость первого экрана.

## Эталоны

DOCX-эталоны платных продуктов в витрину не входят.
