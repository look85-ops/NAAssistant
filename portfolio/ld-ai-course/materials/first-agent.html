Лид-магнит · Бесплатно

Твой первый AI-агент за 15 минут

Никакого кода. Только текст, логика и файлы. Собери помощника, который знает тебя, помнит контекст и работает предсказуемо.

Зачем тебе агент

Обычный чат — это прохожий на улице. Ты задаёшь вопрос → тебе отвечают. Каждый раз с чистого листа. Он забывает контекст через 10 сообщений.

Агент — это сотрудник, которому ты дал должностную инструкцию. Один раз описываешь: кто ты, что тебе нужно, как отвечать. Дальше он работает сам. Помнит тебя, твои файлы, твои решения.

Метафора. Без агента — ты каждый раз нанимаешь нового человека и объясняешь всё с нуля. С агентом — у тебя есть постоянный ассистент, который знает твой стиль, правила и проекты.

Три уровня AI-помощника

Не бросайся к сложному. Начни с того, что подходит под твою задачу.

Уровень 1. Обычный чат (ChatGPT, Claude, DeepSeek)
Когда достаточно: разовые вопросы, черновики, поиск информации.

Уровень 2. Project / Custom GPT (5 минут настройки)
Чат + постоянная инструкция + прикреплённые файлы. Когда достаточно: одна повторяющаяся задача.

Уровень 3. Полноценный агент (15-30 минут, этот гайд)
AI, который живёт в папке, видит файлы, редактирует их, копит знания. Когда нужно: несколько проектов, долгая память, предсказуемость.

Как собрать за 15 минут

  1. Скачай шаблон AGENTS.md — файл, в котором описано, кто твой агент и как он работает.
  2. Заполни 6 полей: Identity (кто он), Core Purpose (зачем), Voice & Tone (как говорит), Boundaries (что можно/нельзя), Workflow (шаги), Memory (какие файлы читать).
  3. Подключи агента. В opencode — положи AGENTS.md в корень проекта. В Claude — вставь в Custom Instructions проекта. В ChatGPT — создай Custom GPT.
  4. Протестируй. Дай простую задачу: «Спроектируй структуру двухдневного курса по [твоя тема]». Похоже на то, как сделала бы ты? Поправь AGENTS.md и повтори.

Примеры задач для методиста

  • Спроектировать структуру учебного модуля по теме [X]
  • Написать сценарий видео-лекции на 7 минут
  • Проверить текст на соответствие tone-of-voice компании
  • Придумать 5 форматов проверки знаний
  • Собрать пост для LinkedIn о новом курсе
  • Разобрать обратную связь от участников и выделить паттерны

Советы для старта

  • Не пиши идеально. Набросай и поправь после 2-3 тестов, а не вылизывай неделю.
  • Дай границы. Чётко пропиши что можно, а что нет. Иначе агент начнёт придумывать.
  • Используй метафоры. Если агент объясняет сложное — пусть приводит примеры из твоей сферы.
  • Обучай агента. Каждый раз когда сделал хорошо → скажи. Каждый раз когда ошибся → объясни почему.
  • Один агент — одна задача. Лучше три маленьких агента, чем один, который ничего не умеет хорошо.
После первого агента ты захочешь: добавить папку знаний (knowledge/), создать бэклог задач, научить агента работать с файлами, добавить суб-агентов для разных типов задач. Шаблон AGENTS.md — для этого.
