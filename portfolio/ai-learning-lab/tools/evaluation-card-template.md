# Evaluation Card

Одна карточка на один вывод AI-системы.

```yaml
test_id: "[уникальный id]"
task: "[что должна сделать система]"
context: "[аудитория и безопасный контекст]"
expected_result: "[что считается полезным]"
status: PASS | FAIL | REVIEW
evidence: "[наблюдаемый фрагмент результата]"
limitation: "[чего система не может заключить]"
human_decision: accept | clarify | reject
next_action: "[одно действие и критерий готовности]"
```

## Мини-практика

1. Возьми один синтетический ответ AI.
2. Заполни карточку, не добавляя несуществующих цифр.
3. Попроси коллегу принять, уточнить или отклонить вывод.
4. Сравни решение с исходной карточкой.

Результат упражнения — не «правильный ответ», а прозрачный маршрут от вывода к решению человека.
