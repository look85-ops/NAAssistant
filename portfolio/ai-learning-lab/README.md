# AI Learning Systems Lab

Публичная лаборатория Наташи. Первый инструмент решает конкретную задачу: собрать сценарий преподавателя и презентацию в один проверяемый комплект со скриншотами слайдов.

## Как работает лаборатория

Лаборатория выпускает не статьи, а повторяемые практические циклы:

`пост → задача → инструмент → результат → разбор следующего шага`

Каждый выпуск можно пройти на синтетическом примере, не передавая наружу
рабочие документы или персональные данные.

## Что опубликовано

- `index.html` — витрина лаборатории.
- `start-here.html` — инструкция для стороннего пользователя.
- `evaluation-kit.md` — открытая рубрика проверок AI в обучении.
- `experiments/one-task-five-roles.md` — эксперимент «одна задача — пять ролей».
- `cases/scenario-to-deck.md` — обезличенный кейс синхронизации сценария и презентации.
- `tools/` — шаблоны, с которых можно начать собственный прогон.
- `posts/` — черновики публикаций для LinkedIn.
- `examples/` — реальные страницы готового сценария со встроенными скриншотами слайдов из большой рабочей пары. Отдельные скрины презентации не публикуются.
- `algorithm-kit/` — полный комплект из папки «Слайды в сценарий: алгоритм»: документы и Python-скрипты.
- `algorithm-kit.zip` — архив комплекта для скачивания.
- `prompts/` — пять копируемых промптов для последовательной мультиагентной работы.

## Что это сейчас

Это не облачный сервис с загрузкой файлов. Публичная часть даёт метод, шаблоны и безопасный синтетический прогон. Обработка реальной пары `.docx` + `.pptx` выполняется отдельно, чтобы рабочие документы не уходили в неизвестное облако.

## Принцип приватности

Материалы используют синтетические или обезличенные примеры. Здесь нет рабочих файлов, названий работодателей, персональных данных, закрытых методик и API-ключей.
