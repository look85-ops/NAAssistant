# Промпты пяти ролей

Комплект для последовательной работы над одной образовательной задачей.

```text
brief -> learning_spec -> draft -> critique -> evaluated_result
```

## Как запускать

1. Передай Аналитику исходный бриф.
2. Передай его результат Методисту без пересказа и потери ограничений.
3. Передай спецификацию Автору сценария.
4. Передай черновик Критику.
5. Передай черновик и критику Eval Owner.
6. Человеку покажи не только финальный текст, но и спорные места, доказательства и решение, которое нужно принять.

Промпты не требуют конкретной модели. Их можно использовать по очереди в одном чате или разнести по пяти агентам.
