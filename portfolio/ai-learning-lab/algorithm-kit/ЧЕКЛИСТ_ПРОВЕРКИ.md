# Чек-лист проверки результата

Что проверить после того, как агент сказал «готово». Проходить сверху вниз;
если что-то «нет» — вернуть агенту, не принимать.

## 1. Файл открывается

- Открывается в Word без ошибки (или `python-docx Document()` не падает).
- Нет оборванных ссылок: каждый `r:embed`/`r:link` в `document.xml` ведёт на
  существующий `word/media/*`; `header*.xml.rels` и `footer*.xml.rels` целы.

## 2. Номера верны

- Все плашки либо «Слайд», либо «Слайд №N» — без мусора вроде «Слайд №1615»
  (признак того, что число разъехалось по нескольким run'ам).
- Номера идут **без убывания** вдоль документа (одна секция может повторять
  номер — допустимо; «назад» к меньшему — подозрительно).
- Диапазон номеров в пределах числа слайдов: без №273 при 268 слайдах.
- Формат единый: либо везде `Слайд №N`, либо везде `Слайд N` (не смесь).

## 3. Картинка соответствует номеру

- Рядом с каждой «Слайд №N» стоит скриншот, и на нём — **нужный** слайд.
  Выборочно сверить 5–8 мест по смыслу: «Слайд №43» должен показывать то, что
  написано рядом в сценарии (например заголовок раздела).
- Все имена файлов `slideNNN.png` совпадают с номером в плашке.

## 4. Размер и оформление

- Скрины одной высоты — 5,5 см (16:9, ширина ≈ 9,78 см), как первый скрин
  в эталонном сценарии.
- Плашка и картинка на одном фоне (тот же светло-голубой `CCECFF`), ничего
  не сбито в заголовке/шапке/футере.

## 5. Ничего лишнего не удалено

- Служебная графика документа (эмблемы в карточке, логотип в колонтитуле,
  WMF/EMF-значки) — на месте.
- Оригинальные тексты сценария не изменены (кроме самих плашек и вставок).

## 6. Спорные места — отдельным списком

- Агент обязан был выдать список мест без уверенного соответствия. Перечисли
  их человеку для решения, НЕ принимай «добитые» угаданные номера молча.

## 7. Авто-проверка (по желанию)

Скрипт-валидатор, если есть под рукой:

```python
# подсчёт номеров и проверка монотонности + убывание -> красный флаг
import re
nums = [int(m.group(1)) for p in paragraphs
        if (m := re.match(r'Слайд №(\d+)', p.text))]
assert all(a <= b for a, b in zip(nums, nums[1:])), 'номера убывают!'
```

## Красные флаги (сразу вернуть)

- Файл не открывается.
- Номера «скачут» (20 → 9 → 21).
- Номер вне диапазона числа слайдов.
- Скрин под «Слайд №N» показывает явно другой слайд.
- В документе остались обрывки удалённых плашек/картинок (пустые рамки).
