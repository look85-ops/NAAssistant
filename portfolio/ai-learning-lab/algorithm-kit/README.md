# Слайды в сценарий: рабочий алгоритм

Отработанный способ расставить «Слайд №N» в сценарии (.docx) по управляющей
презентации (.pptx) и вставить скриншоты слайдов — туда, где преподаватель видит
и текст, и слайд.

## Почему этот способ (а не старый)

Раньше скрипты ставили номера **по порядку** («первая метка → слайд 1») и
пересохраняли документ через `python-docx` — это ломало форматирование и
разъезжалось, когда дизайнер менял колоду. Здесь другой принцип:

1. Номер слайда определяется по **текстовому соответствию** (что написано в
   сценарии = что написано на слайде), а не по счётчику.
2. Вставка идёт **только через XML/ZIP** (`lxml` + `zipfile`), файл не
   пересохраняется целиком.

## Три шага

| Шаг | Что делает | Скрипт |
|---|---|---|
| 1. Render | Экспорт слайдов .pptx в PNG через PowerPoint | `1_render.py` |
| 2. Match | Сопоставляет плашки «Слайд» со слайдами по TF-IDF + выравнивание | `2_match.py` |
| 3. Insert | Ставит «Слайд №N» и вставляет скрин под плашку | `3_insert.py` |

Подробное описание каждого шага и грабли — `АЛГОРИТМ.md`.

## Быстрый старт

1. Открой `1_render.py`, `2_match.py`, `3_insert.py` — в начале каждого задай
   пути к своим `.pptx` и `.docx`.
2. Запускай по порядку:
   ```
   py 1_render.py
   py 2_match.py
   py 3_insert.py
   ```
3. После `2_match.py` проверь отчёт `match_report.txt` — особенно разделы
   «якоря» (должны сойтись 1:1) и «сомнительные» (слабая уверенность).

## Требования

- Windows, установленный Microsoft PowerPoint (нужен для экспорта PNG).
- Python 3.10+ с пакетами: `pywin32`, `python-docx`, `lxml`.
  ```
  py -m pip install pywin32 python-docx lxml
  ```

## Что делать нельзя

- Не пересохранять документ через `python-docx.save()` — только XML/ZIP.
- Не угадывать номер при слабой уверенности — оставить плашку пустой и спросить.
- Не трогать картинки, на которые ссылаются `header*.xml.rels` / `footer*.xml.rels`.
