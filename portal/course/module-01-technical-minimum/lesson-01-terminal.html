Урок 1. Терминал и командная строка

Урок 1

  • Открыть PowerShell и не испугаться
  • Ориентироваться в файловой системе через команды
  • Создавать, копировать, удалять файлы и папки
  • Объяснить коллеге разницу между cmd и PowerShell

Прямо сейчас: откройте терминал. Windows: Win → «PowerShell» → Enter. Mac: Cmd+Пробел → «Terminal» → Enter. Видите приглашение командной строки? Это ваша первая победа. Дальше — как им пользоваться.

Зачем это L&D-специалисту

Почти все мощные AI-инструменты живут не в браузере, а в терминале: запуск AI-агентов, запросы к API моделей (OpenRouter, OpenAI), управление AI-скриптами, работа с ассистентами вроде Claude Code. Терминал — это пульт управления технологиями. Без него вы не сможете ни починить сломавшийся AI-пайплайн, ни объяснить разработчику, что вам нужно, ни тем более запустить AI-агента самостоятельно.

К концу этого урока вы сможете открыть командную строку, ориентироваться в файловой системе, создавать и удалять файлы и папки, смотреть содержимое — и не бояться чёрного окна. Это база, без которой нельзя работать с Git, API и кодом.

Что такое командная строка

Командная строка (терминал) — это способ общаться с компьютером через текст. Вместо того чтобы кликать по папкам мышкой, вы пишете команду, и компьютер её выполняет.

Звучит как шаг назад, но на деле:

  • Быстрее. Одна команда заменяет 5 кликов.
  • Точнее. Вы говорите компьютеру «создай папку X в папке Y», а не ищете нужное меню.
  • Автоматизируемо. Команды можно записать в скрипт и повторять хоть 100 раз.
Метафора. Разработчики, админы, аналитики данных — все живут в терминале. Это как стетоскоп для врача: сначала непривычно, потом без него никуда.

Файловая система — это дерево

Представьте шкаф с папками. Внутри шкафа — полки (диски: C:, D:). На полках — папки. В папках — другие папки и файлы.

Вы всегда стоите в какой-то точке этого дерева. Команды — это способ сказать:

  • «Покажи, где я стою» — pwd
  • «Покажи, что вокруг» — ls
  • «Перейди в соседнюю папку» — cd папка
  • «Создай здесь новую папку» — mkdir имя

Пути: абсолютные и относительные

  • Абсолютный путь — от корня диска: C:\Users\ИмяПользователя\Desktop\проект
  • Относительный путь — от текущей папки: .\папка (здесь), ..\ (на уровень выше)

Если я скажу «создайте папку в текущей директории» — я использую относительный путь. Если «откройте папку на рабочем столе» — абсолютный.

Терминал — не шаг назад. Это шаг в сторону точного управления компьютером. Через полгода вы будете удивляться, как жили без него.

Командная строка в Windows

У вас Windows, поэтому ваш терминал — PowerShell.

cmd vs PowerShell: cmd.exe — это старая командная строка из 90-х. PowerShell — современная, с поддержкой скриптов, объектов и цветового выделения. Всегда открывайте PowerShell, а не cmd.

Как открыть: нажмите Win → напишите PowerShell → Enter.

Вы увидите что-то вроде:

Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.

PS C:\Users\ИмяПользователя>

Строка с PS C:\Users\ИмяПользователя> — это приглашение (prompt). Оно показывает, где вы сейчас находитесь (в вашей домашней папке).

➤ Попробуйте
Откройте PowerShell прямо сейчас и введите pwd. Вы увидите свой текущий путь. Потом введите ls — увидите содержимое домашней папки: Desktop, Documents, Downloads. Затем ls C:\ — содержимое корня диска. Чувствуете разницу?

Промежуточный итог

Вы знаете, что терминал — это не страшное чёрное окно, а способ точного управления компьютером. Вы умеете открыть PowerShell, посмотреть где вы находитесь (pwd) и что вокруг (ls). Дальше — шпаргалка и практика.

Терминал — пульт управления, без которого AI за стеклом

Вы не можете собрать мебель, глядя на неё через витрину. С AI так же: чтобы запустить агента, отправить запрос к модели, настроить пайплайн — нужен прямой доступ. Терминал даёт этот доступ. После этого урока стекла больше нет.

Практика

Упражнение 1. Первый вход (5 мин)

Откройте PowerShell. Вы увидите строку приглашения PS C:\Users\ИмяПользователя>. Выполните:

pwd

Увидите текущий путь.

ls

Содержимое домашней папки: Desktop, Documents, Downloads.

ls C:\

Содержимое всего диска C.

Упражнение 2. Навигация (10 мин)
  1. Перейдите на рабочий стол: cd C:\Users\ИмяПользователя\Desktop → ls
  2. Перейдите в одну из папок: cd "Название папки" (кавычки нужны, если есть пробелы)
  3. Проверьте, где вы: pwd
  4. Вернитесь на уровень выше: cd .. → pwd
Упражнение 3. Создайте структуру (15 мин)
  1. Перейдите в папку вашего рабочего проекта для курса
  2. Создайте папку: mkdir terminal-demo
  3. Перейдите в неё: cd terminal-demo
  4. Создайте три подпапки: mkdir theory, practice, artifacts
  5. Проверьте: ls — увидите три новые папки
Упражнение 4. Работа с файлами (15 мин)
  1. Создайте файл: ni theory\cheatsheet.md
  2. Проверьте: ls theory
  3. Откройте cheatsheet.md в редакторе и запишите 5 команд, которые запомнили
  4. Проверьте через терминал: cat theory\cheatsheet.md
Упражнение 5. Дописывайте из терминала (10 мин)
  1. Допишите строку: "cls — очистить экран" >> theory\cheatsheet.md
  2. Проверьте: cat theory\cheatsheet.md — строка добавилась
  3. Попробуйте перезапись (осторожно!): "# Моя новая шпаргалка" > theory\cheatsheet.md
  4. Проверьте: cat theory\cheatsheet.md — содержимое заменилось
  5. Верните как было через редактор (или оставьте — вы в изолированной папке)

Важно: >> дописывает в конец, > перезаписывает весь файл.

Упражнение 6. Сохраните вывод (5 мин)
  1. Вернитесь в папку проекта: cd ..
  2. Сохраните список файлов: ls > terminal-demo\artifacts\filelist.txt
  3. Проверьте: cat terminal-demo\artifacts\filelist.txt
Упражнение 7. Копирование и перемещение (10 мин)
  1. Скопируйте шпаргалку: cp terminal-demo\theory\cheatsheet.md terminal-demo\practice\cheatsheet.md
  2. Проверьте: ls terminal-demo\practice
  3. Переименуйте: mv terminal-demo\practice\cheatsheet.md terminal-demo\practice\cheatsheet-backup.md
  4. Удалите файл: del terminal-demo\practice\cheatsheet-backup.md
  5. Удалите папку: rm -r terminal-demo\practice
  6. Проверьте: ls terminal-demo — theory и artifacts остались

После практики

Чек-лист готовности

  • ✓ Открывали PowerShell, выполняли pwd, ls, cd
  • ✓ Создали папку terminal-demo и структуру внутри
  • ✓ Создали файл cheatsheet.md через терминал и заполнили
  • ✓ Дописали строку через >> и поняли разницу с >
  • ✓ Сохранили вывод команды в файл (ls > filelist.txt)
  • ✓ Копировали, перемещали, удаляли файлы

Артефакт урока

После урока в вашем проекте должна появиться структура:

ваш-проект/
└── terminal-demo/
    ├── theory/
    │   └── cheatsheet.md
    └── artifacts/
        └── filelist.txt

Челлендж на завтра

Откройте PowerShell первым делом с утра. Не проводник — терминал. Выполните pwd, ls, перейдите в папку проекта через cd. 3 минуты. Сделайте это привычкой — завтра, послезавтра, через неделю. Терминал перестанет быть чужим.

Что дальше

На следующем уроке — Git. Вы научитесь сохранять версии файлов, делать коммиты и не бояться слова «репозиторий». Но сначала закрепите терминал. Если какой-то шаг был непонятен — вернитесь и повторите.

Дополнительно (необязательно, но полезно)

  • Введите Get-Help ls — встроенная справка по команде
  • Введите ls * — покажет содержимое всех папок внутри текущей
  • Введите Write-Host "Привет, мир!" — терминал напечатает «Привет, мир!»
