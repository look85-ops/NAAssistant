Урок 1. Терминал и командная строка

**Модуль 1:** · **Время:**

Модуль 1: Технический минимум: читать, понимать, коммитить Неделя: 1 из 3 Время: 2–2.5 ч

1. Цель недели

Зачем это L&D-специалисту в работе с AI.

Почти все мощные AI-инструменты живут не в браузере, а в терминале: запуск AI-агентов, запросы к API моделей (OpenRouter, OpenAI), управление AI-скриптами, работа с ассистентами вроде Claude Code. Терминал — это пульт управления технологиями. Без него вы не сможете ни починить сломавшийся AI-пайплайн, ни объяснить разработчику, что вам нужно, ни тем более запустить AI-агента самостоятельно.

К концу этого урока вы сможете открыть командную строку, ориентироваться в файловой системе, создавать и удалять файлы и папки, смотреть содержимое — и не бояться чёрного окна. Это база, без которой нельзя работать с Git, API и кодом.

2. Теория

Что такое командная строка

Командная строка (терминал) — это способ общаться с компьютером через текст. Вместо того чтобы кликать по папкам мышкой, вы пишете команду, и компьютер её выполняет.

Звучит как шаг назад, но на деле:

  • Быстрее. Одна команда заменяет 5 кликов.
  • Точнее. Вы говорите компьютеру «создай папку X в папке Y», а не ищете нужное меню.
  • Автоматизируемо. Команды можно записать в скрипт и повторять хоть 100 раз.

Разработчики, админы, аналитики данных — все живут в терминале. Это как стетоскоп для врача: сначала непривычно, потом без него никуда.

Файловая система — это дерево

Представьте шкаф с папками. Внутри шкафа — полки (диски: C:, D:). На полках — папки. В папках — другие папки и файлы.

Вы всегда стоите в какой-то точке этого дерева. Команды — это способ сказать: - «Покажи, где я стою» - «Покажи, что вокруг» - «Перейди в соседнюю папку» - «Создай здесь новую папку»

Пути: абсолютные и относительные

  • Абсолютный путь — от корня диска: C:\Users\ИмяПользователя\Desktop\проект
  • Относительный путь — от текущей папки: .\папка (здесь), ..\ (на уровень выше)

Если я скажу «создайте папку в текущей директории» — я использую относительный путь. Если «откройте папку на рабочем столе» — абсолютный.

Командная строка в Windows

У вас Windows, поэтому ваш терминал — PowerShell (не путайте с обычной командной строкой cmd.exe, она старше и слабее). PowerShell стоит на всех современных Windows и умеет больше.

Как открыть: нажмите Win → напишите PowerShell → Enter.

3. Шпаргалка (сохраните себе)

Навигация

Действие Команда PowerShell Аналог в проводнике
Где я? pwd Строка адреса
Что внутри? ls (или dir, Get-ChildItem) Открыть папку
Перейти в папку cd \путь Двойной клик по папке
На уровень выше cd .. Alt + Стрелка вверх
На корень диска cd \ —
Домой (ваш профиль) cd ~ —

Работа с папками и файлами

Действие Команда
Создать папку mkdir имя
Создать файл ni имя.txt (ni = New-Item)
Удалить файл del имя.txt
Удалить папку с содержимым rm -r имя
Скопировать cp откуда куда
Переместить / переименовать mv откуда куда
Посмотреть файл cat файл.txt
Посмотреть первые N строк gc файл.txt -TotalCount 5

Навигация в терминале

Действие Что даёт
Tab Автодополнение: начали вводить cd Des → жмёте Tab → cd Desktop
Стрелка вверх Поднимает предыдущую команду
cls Очистить экран
> Записать вывод команды в файл: ls > список.txt
>> Дописать в конец файла: "новая строка" >> файл.txt

4. Практика

Выполняйте последовательно. Если на каком-то шаге ошибка — остановитесь и напишите мне, что пошло не так.

Упражнение 1. Первый вход (5 мин)

Откройте PowerShell. Вы увидите что-то вроде:

Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.

PS C:\Users\ИмяПользователя>

Строка с PS C:\Users\ИмяПользователя> — это приглашение (prompt). Оно показывает, где вы сейчас находитесь (в вашей домашней папке).

Выполните по порядку:

pwd

Вы увидите свой текущий путь. Теперь:

ls

Это содержимое вашей домашней папки. Видите Desktop, Documents, Downloads?

Теперь:

ls C:\

Это содержимое всего диска C. Чувствуете разницу?

Упражнение 2. Навигация (10 мин)

Перейдите на рабочий стол:

cd C:\Users\ИмяПользователя\Desktop
ls

Вы видите свои папки и файлы. Перейдите в одну из них (например, туда, где будете работать):

cd "Название папки"

Обратите внимание на кавычки: если в имени папки есть пробелы, без кавычек PowerShell подумает, что слова разделены.

Проверьте, где вы:

pwd

Вернитесь на уровень выше:

cd ..
pwd

Снова на рабочем столе.

Упражнение 3. Создайте структуру (15 мин)

Перейдите в папку вашего рабочего проекта (ту, где вы храните файлы для курса). Создайте внутри папку terminal-demo:

mkdir terminal-demo

Перейдите в неё и создайте три подпапки:

cd terminal-demo
mkdir theory, practice, artifacts
ls

Вы увидите три новых папки. Поздравляю — вы создали структуру из командной строки. Без мышки.

Упражнение 4. Работа с файлами (15 мин)

Создайте файл шпаргалки:

ni theory\cheatsheet.md

Проверьте, что он появился:

ls theory

Теперь откройте файл в любом текстовом редакторе (блокнот, VS Code, Notepad++) и запишите 5 команд, которые запомнили, в формате:

# Моя шпаргалка

pwd — показывает текущую папку
ls — показывает содержимое папки
cd .. — перейти на уровень выше
mkdir — создать папку
ni — создать файл

Сохраните, закройте редактор. Вернитесь в терминал и проверьте, что записалось:

cat theory\cheatsheet.md

Упражнение 5. Дописывайте из терминала (10 мин)

Добавьте новую строку прямо из командной строки, без редактора:

"cls — очистить экран" >> theory\cheatsheet.md
cat theory\cheatsheet.md

Видите, строка добавилась? >> дописывает в конец, > перезаписывает весь файл.

Попробуйте перезапись:

"# Моя новая шпаргалка" > theory\cheatsheet.md
cat theory\cheatsheet.md

Содержимое заменилось. Верните как было (через редактор или отмените — не бойтесь экспериментировать, вы в изолированной папке).

Упражнение 6. Сохраните вывод команды (5 мин)

Сделайте список файлов проекта и сохраните в файл:

cd C:\Users\ИмяПользователя\Desktop\путь\к\проекту
ls > terminal-demo\artifacts\filelist.txt
cat terminal-demo\artifacts\filelist.txt

Теперь у вас есть текстовый файл со списком содержимого папки. Это удобно, если нужно сохранить «слепок» папки.

Упражнение 7. Копирование и перемещение (10 мин)

Скопируйте шпаргалку в папку practice:

cp terminal-demo\theory\cheatsheet.md terminal-demo\practice\cheatsheet.md
ls terminal-demo\practice

Теперь переименуйте её (переместите с новым именем):

mv terminal-demo\practice\cheatsheet.md terminal-demo\practice\cheatsheet-backup.md
ls terminal-demo\practice

Удалите ненужный файл:

del terminal-demo\practice\cheatsheet-backup.md
ls terminal-demo\practice

Папка practice пуста. Удалите и её:

rm -r terminal-demo\practice
ls terminal-demo

Папка practice исчезла, theory и artifacts остались.

Упражнение 8. Создайте файл рефлексии (10 мин)

Создайте файл reflection.md в папке artifacts:

ni terminal-demo\artifacts\reflection.md

Откройте в редакторе и напишите ответы на три вопроса:

  1. Чем командная строка удобнее проводника, а чем неудобнее?
  2. В каком моменте я завис(ла) / было непонятно?
  3. Что из этого я уже могу применить в своей работе?

Сохраните и закройте. Проверьте через терминал:

cat terminal-demo\artifacts\reflection.md

5. Рефлексия (напишите мне)

  1. Сколько времени заняло?
  2. Что было самым непонятным?
  3. Что было самым полезным?
  4. Оценка материала от 1 до 5

  • [ ] Дописали строку через >> и поняли разницу с >

7. Артефакт

После урока в вашем проекте должна появиться структура:

ваш-проект/
└── terminal-demo/
    ├── theory/
    │   └── cheatsheet.md
    └── artifacts/

        └── reflection.md

8. Что дальше

На следующей неделе — Git. Вы научитесь сохранять версии файлов, делать коммиты и не бояться слова «репозиторий».

Но сначала закрепите терминал. Если какой-то шаг был непонятен — вернитесь и повторите. Если всё понятно — отлично, вы прошли базовый курс молодого бойца.

Дополнительно (необязательно, но полезно)

  • Введите Get-Help ls — это встроенная справка по команде
  • Введите ls * — покажет содержимое всех папок внутри текущей
  • Введите Write-Host "Привет, мир!" — терминал напечатает «Привет, мир!»
