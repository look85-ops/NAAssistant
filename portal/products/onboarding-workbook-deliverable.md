# AI для онбординга: 5 промптов, которые запустят адаптацию за 2 часа

> Воркбук. Скопировано → вставлено → работает.

---

## Введение

Вы тратите на онбординг 10–30 часов в месяц. Рассказываете одно и то же, проверяете одно и то же. А новичок всё равно спрашивает: «Где шкаф с чаем?»

Этот воркбук — про завтрашний понедельник. Открываете → копируете промпт → вставляете в ChatGPT → получаете инструмент.

**Что внутри:** 5 промптов + сценарий внедрения + чек-лист + шпаргалка.

**Как использовать:** копируете промпт → заменяете [текст в скобках] → отправляете в чат с AI.

## 1. AI-план онбординга под роль

Индивидуальный 5-недельный план адаптации: по дням, с конкретными встречами и заданиями.

### Промпт

```
system: Ты — старший методист корпоративного обучения с 15-летним опытом. Специализация — онбординг. Ты проектируешь планы адаптации, которые снижают time-to-productivity на 30%. Пишешь на русском, конкретно, без менторства.

Составь план онбординга для [ДОЛЖНОСТЬ] в [КОМПАНИЯ/ОТРАСЛЬ].

Контекст:
- Опыт новичка: [с опытом / без опыта / после смежной роли]
- Команда: [N] человек
- Инструменты: [перечислить]
- Задачи роли: [2-3 предложения]
- Формат: [офис / удалёнка / гибрид]

Разбей на 5 недель. Для каждой укажи:
1. Тема недели
2. С кем встретиться (конкретные роли)
3. Что изучить (документы, системы, курсы)
4. Практическое задание
5. Чек-поинт с руководителем (1-2 вопроса на пятницу)

Первая неделя — ощущение «я справляюсь». Предусмотри дни без новых встреч. Укажи, кто отвечает за каждый блок.
```

### Как адаптировать

Замените [ДОЛЖНОСТЬ] и [ИНСТРУМЕНТЫ] на свои. Для плана на 3 месяца — допишите «разбей на 12 недель». Сохраните в Google Docs → отправьте руководителю.

## 2. AI-бадди для новичка

FAQ-бот на базе документов компании. Новичок спрашивает — бот отвечает. 80% вопросов без вас.

### Промпт

```
system: Ты — внутренний помощник [КОМПАНИЯ]. Отвечаешь на вопросы новых сотрудников по документам компании. Кратко (3-5 предложений), дружелюбно. Не знаешь — честно: «Спроси у [ИМЯ HR]». Никогда не выдумываешь правила.

База знаний:
=== ОФИС ===
[правила, карта, контакты]
=== IT-ДОСТУПЫ ===
[инструкции по доступам]
=== КОМАНДИРОВКИ ===
[регламент]
=== FAQ ===
[частые вопросы и ответы]
```

### Быстрый старт (15 мин)

1. Соберите 5-10 внутренних документов в один файл
2. Скопируйте тексты в промпт после «База знаний:»
3. Задайте пробный вопрос: «Как получить доступ к почте?»
4. Проверьте ответ. Если ошибка — добавьте инфо в базу
5. Отправьте ссылку на чат новичку

**Важно:** один чат = один новичок. Для каждого — новый.

## 3. Чек-лист первого дня

Почасовой план. Не «познакомиться с командой», а «10:00 — HR выдаёт пропуск и показывает кухню».

### Промпт

```
system: Ты — HR-менеджер [КОМПАНИЯ]. Ты делаешь так, чтобы к вечеру первого дня новичок чувствовал: «Я попал в хорошее место». Тёплый, внимательный тон.

Составь почасовой чек-лист первого дня для [ДОЛЖНОСТЬ].

Условия:
- Формат: [офис / удалёнка]
- Начало дня: [время]
- Обед: [время]
- Команда: [N] человек, [опенспейс / кабинеты]

Для каждого часа: время, действие, кто отвечает, что новичок получает на руки.

Не включать в первый день: обучение инструментам, >5 новых людей подряд, чтение регламентов >15 мин.

Обязательно: встреча с руководителем 1-на-1, обед с командой, 30 мин «просто осмотреться».
```

### Почему работает

Большинство чек-листов — абстрактные. AI даёт конкретику под вашу компанию. Остаётся распечатать и раздать.

## 4. Письмо-приветствие от руководителя

Тёплое welcome-письмо накануне первого дня. Снижает тревожность. «Меня ждали».

### Промпт

```
system: Ты — руководитель отдела [НАЗВАНИЕ]. Пишешь письмо новому сотруднику, который выходит завтра. Человеческий тон, без канцелярита. Не ставишь задачи — приглашаешь в команду.

Напиши welcome-письмо для [ИМЯ], должность [ДОЛЖНОСТЬ].

Контекст:
- Что делает отдел: [2-3 предложения]
- Кто встретит: [ИМЯ]
- Что важно знать заранее: [дресс-код, парковка, что взять]

Требования:
- 3-4 коротких абзаца
- Начало: «[Имя], привет!»
- 1 абзац — что делаем и зачем
- 1 абзац — что ждёт в первый день (без пугающих деталей)
- 1 абзац — практическая информация
- Конец: «До завтра, [ИМЯ РУКОВОДИТЕЛЯ]»
- Никаких «в соответствии с регламентом» и «вверенный участок»
```

### Совет

Отправьте накануне вечером. Сотрудник прочитает дома с чаем — и придёт уже «своим». 2 минуты на замену переменных.

## 5. Оценка онбординга через 30 дней

Опросник, на который хочется отвечать. 7 вопросов — 5 минут.

### Промпт

```
system: Ты — L&D-методист. Проектируешь опросники, на которые люди отвечают с удовольствием. Никаких «оцените по шкале». Вопросы цепляют за живое.

Составь опросник «Как прошёл твой первый месяц» для [ДОЛЖНОСТЬ].

Требования:
- 7-8 вопросов
- Только 2 со шкалой 0-10, остальные открытые
- Блок 1 (3 вопроса): ощущения — «Что чувствуешь спустя месяц?», «Что было самым трудным?»
- Блок 2 (3 вопроса): процессы — «Какой информации не хватило?», «Что узнал слишком поздно?», «Кто из коллег помог больше всего?»
- Блок 3 (2 вопроса): будущее — «Что бы изменил для следующего новичка?», «Твой совет руководителю одним предложением»
- Финальный вопрос: «Насколько уверен, что останешься через год?» (0-10)
- Без «оцените качество инструктажа»
```

### Когда отправлять

- День 28-30. Не раньше.
- Отправляет руководитель личным сообщением.
- Если на вопрос «останешься через год» ниже 7 — красный флаг, повод для разговора.

## Сценарий внедрения за 4 шага

### Шаг 1 (ПН, 40 мин): Один промпт через себя
Выберите ОДИН шаблон под самую острую боль. Скопируйте → замените [переменные] → отправьте в ChatGPT → посмотрите результат. Не пытайтесь внедрить всё сразу.

### Шаг 2 (ВТ, 30 мин): Покажите руководителю
Скажите: «Я подготовил план адаптации для нового менеджера. Посмотри — норм?» Руководитель видит пользу, а не технологию.

### Шаг 3 (СР, 20 мин): Запустите на одном новичке
Не на потоке. На одном. Дайте ему AI-бадди или план. Через неделю спросите: «Помогло?»

### Шаг 4 (ПТ, 15 мин): Замерьте результат
Две цифры: (1) сколько раз новичок обратился к вам с вопросами за неделю, (2) что он помнит из плана адаптации. Через месяц — опросник (Шаблон 5).

**ПН:** выбрать 1 шаблон → собрать документы компании → скопировать промпт → получить результат → сохранить в Google Docs

**СР:** дать одному новичку → через 2 дня спросить «что работает?» → записать 2-3 правки → подготовить второй шаблон

**ПТ:** замерить результат → показать цифры руководителю → сохранить рабочие промпты в общую папку → выбрать следующий шаблон

## Шпаргалка параметров AI-модели

| Параметр | Что делает | Значение для воркбука |
|---|---|---|
| **System prompt** | Задаёт роль AI («ты — методист») | Всегда прописывайте первым |
| **Temperature** | Креативность (0 — строго, 2 — хаос) | 0.5-0.7 для всех шаблонов |
| **Model** | Какая версия AI | ChatGPT (GPT-4o) или Claude (Sonnet) |

Что НЕ настраивать: top-p, frequency penalty — технические ручки, не для вас.
