# Наоборот

Небольшой бренд печатных открыток-состояний. В проекте сначала собираем физический MVP, затем показываем его в фотографиях и только после этого принимаем решение о тираже.

## Рабочее решение

- Основной продукт: готовая печатная колода.
- PDF не продаём как отдельный товар на этапе MVP.
- Формат тестовой печати: A5 с вылетом 3 мм.
- Одна сторона карточки = одна страница PDF.
- GIMP пока не устанавливаем: для этой задачи важнее верстка, типографика и печатная проверка.

## Роли агентов

| Роль | Результат | Когда подключать |
|---|---|---|
| `product-analyst` | состав MVP, цена, критерии готовности | до нового набора или тиража |
| `ui-designer` | композиция, сетка, типографика, безопасные поля | до сборки мастер-макета |
| `artist` | SVG, орнаменты, фактуры и декоративные мотивы | если карточкам не хватает собственного образа |
| `art-critic` | отбраковка слабых вариантов и проверка цельности | перед тестовой печатью и фотосъемкой |
| `frontend_developer` | HTML/CSS-макет и браузерный экспорт | когда макет выбран |
| `post-writer` | описание продукта, посты, текст карточки товара | после фото физического MVP |
| `belarusian-philologist` | белорусские названия и тексты | только при появлении белорусского текста |

## Один цикл работы

1. `product-analyst` фиксирует, что именно проверяем в MVP.
2. `ui-designer` делает один мастер-макет и два варианта только там, где есть реальный выбор.
3. `art-critic` проверяет, не выглядит ли набор случайным или дешевым.
4. `frontend_developer` собирает печатный PDF с вылетами и безопасными полями.
5. Печатаем 2–3 карточки физически, смотрим на размер текста, цвет и совмещение оборота.
6. После физической проверки собираем всю колоду и делаем фото для продаж.

## Критерий готовности MVP

- три карточки распечатаны и проверены в руках;
- текст читается без напряжения при обычном освещении;
- лицевая и оборотная стороны не конфликтуют по цвету и плотности;
- после резки нет белых полос;
- есть 5–7 фотографий продукта и одна фотография комплекта;
- понятны себестоимость, упаковка и следующий шаг продаж.

## Инструменты

- HTML/CSS и браузерный PDF — быстрый мастер для текста и серий карточек;
- Scribus — следующий шаг для финального типографского PDF, если типография потребует PDF/X и CMYK;
- Inkscape — векторные иллюстрации и орнаменты;
- GIMP — только обработка фото и растровых фактур, если они появятся.

## Что не делать сейчас

- не устанавливать несколько редакторов «на всякий случай»;
- не делать отдельный продаваемый PDF;
- не собирать полный тираж до физической цветопробы;
- не смешивать новые исходники с архивом `projects/minsk-map/`.
