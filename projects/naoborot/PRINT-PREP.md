# Печатная подготовка «Наоборот»

Коротко и по делу: что нужно для типографии и как победить смещение сторон на офисном принтере.

## Термины
- **Обрезной формат (trim)** — итоговый размер карточки, например A6 105×148 мм.
- **Вылеты (bleed)** — фон/цвет продолжаются за линию реза на 3 мм с каждой стороны. Нужны, чтобы после резки не было белых полос.
- **Безопасное поле (safe)** — важный текст/логотип не ближе 4–5 мм к линии реза.
- **Метки реза (crop marks)** — короткие линии по углам, по ним режут.
- **Дуплекс** — двусторонняя печать.

## Спецификация для типографии (базовая)
- Формат: A6 105×148 мм (или свой), **с вылетами 111×154 мм**.
- Бумага: матовая/дизайнерская 300–350 г/м².
- Печать: двусторонняя, 4+4, **CMYK**.
- Шрифты: в кривые/встроены. Изображения 300 dpi.
- Цвет: попросить цветопробу; кислотные оттенки в CMYK притухают.
- Файл: PDF/X или PDF с метками реза и вылетами, без масштабирования.

## Почему на офисном принтере стороны «съезжают»
Принтер тянет лист с допуском 1–3 мм, переворот тоже даёт люфт. Это норма, не брак макета.

## Как печатать тест дома и не мучиться
1. **Не печатай «в край»**: фон и рамки держи внутри безопасного поля (5 мм), тогда сдвиг 1–2 мм не заметен.
2. **Зазоры между карточками 8–10 мм**: при резке прощаешь смещение.
3. **Калибровка дуплекса**: напечатай калибровочный лист (`print/duplex-calibration.pdf`), посмотри на просвет, измерь сдвиг крестов по X и Y.
4. **Компенсация**: если, например, оборот уехал на 2 мм вправо — сдвинь содержимое оборота в макете на −2 мм по X (или используй настройку duplex adjust в драйвере).
5. **Резка**: режь по линейке внутри зазора, а не по краю карточки.

## Что делаем в макете (препресс-версии)
- вылеты 3 мм с каждой стороны;
- метки реза;
- безопасные поля 5 мм (текст уже с отступами);
- увеличенные зазоры между карточками;
- отдельные страницы «лицо»/«оборот» для ручной duplex-печати или файл под типографию с imposition.

## Чек-лист перед отправкой в печать
- [ ] Формат и вылеты совпадают.
- [ ] Текст не ближе 5 мм к резу.
- [ ] Все шрифты встроены/в кривые.
- [ ] Цвет CMYK + пробный оттиск.
- [ ] Двусторонние стороны проверить на калибровочном листе.
- [ ] Печать 100% (не «по размеру страницы»).
