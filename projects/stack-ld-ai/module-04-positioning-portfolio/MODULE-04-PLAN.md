# Модуль 4. Позиционирование и портфолио L&D+AI

**2 недели, по 2–2.5 ч** | Пилот для коллег

Три модуля позади: вы умеете работать с AI на уровне инструментов, агентов и стратегии. Теперь вопрос: **как упаковать это в историю, которая продаёт вас как специалиста?**

---

## Неделя 1. Позиционирование: ваш AI-нарратив

- От «я методист» к «я делаю X с помощью AI за Y времени вместо Z».
- Elevator pitch в трёх форматах: 30 секунд / 2 минуты / 5 минут.
- Кейсы из своих проектов: формула «задача → AI-решение → цифры».
- Narrative: одна история, три версии под разные аудитории (HR, руководитель, коллега-методист).

## Неделя 2. Портфолио: от артефактов к продукту

- Что у вас уже есть: собираем артефакты из модулей 1–3 в читаемый пакет.
- Структура сильного портфолио: не «10 инструментов», а «3 кейса с результатом».
- GitHub Pages за час: из README и ссылок → сайт-визитка.
- LinkedIn-профиль: секция «О себе» с AI-нарративом, Featured с портфолио.

## На выходе

- `career/narrative.md` — elevator pitch (3 формата) + 3 кейса
- GitHub Pages — сайт-визитка с портфолио
- Обновлённый LinkedIn-профиль
